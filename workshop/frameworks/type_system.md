# The Type System — Axiom · Proto-Axiom · Pattern · Instance

*Promoted 2026-06-27. Canon layer. Closes Frontier A. Dissolves reserved_zero.*

---

## Why this document exists

The canon crystallization pass (2026-06-09) returned near-pure subtraction. One edge it could not close: **Frontier A — the origin has no inheritors yet.** `witness_as_origin` is ratified, but its four candidate inheritors all paper-collapsed to existing canon. The pass named this as a frontier — either a true zero needs no children, or it is a genus awaiting a species it doesn't have yet. Paper cannot tell which.

It can be told now. The answer is not a new pattern. It is a type distinction the canon was using without naming.

`witness_as_origin` has no inheritors because **it is not a pattern**. It is an **axiom**. Axioms need no children — they are the floor. Frontier A dissolves the moment the type is named.

## The Four Types

### Axiom

The floor. A statement that cannot be derived from anything inside the framework — it is the precondition for everything else being derivable. Axioms have no inheritors because inheritance is a pattern-level relationship; axioms are prior to that relationship.

**Characteristics:**
- Cannot be falsified by a counterexample inside the framework (a counterexample to an axiom exits the framework)
- Needs no instances to be real — it is what makes instances possible
- When correctly named, it feels obvious rather than discovered
- The naming is the whole work; there is nothing to build below it

**Current axioms in the canon:**

| Axiom | The floor it lays |
|---|---|
| `witness_as_origin` | The body is the zero of the witnessing coordinate system. Everything else is measured *from* here. Trusting it or failing closed are the only two moves — not because the body is infallible, but because auditing the origin produces a new origin, not a check. |
| `consented_ledger` | Every move either circulates forward, feels-and-refuses, or commits the forbidden third (externalize-and-hide). This is not a description of what good actors do. It is the structural exhaustion of the options — the three are all there are. |

**Note on count:** Two axioms is the minimum that also accounts for the internal/external split — one governing self-measurement, one governing cost-circulation. Whether a third axiom is latent is an open body-question; the current pass surfaces none.

### Proto-Axiom

A pattern whose work is to accumulate naming pressure toward an axiom until the axiom surfaces. Proto-axioms are falsifiable, subject to composition, and properly belong in the library — but their function is not primarily to describe a mechanism. Their function is to keep pointing at the floor until the floor is named.

**Characteristics:**
- Has a falsifier (unlike axioms)
- When the axiom it points toward is named, the proto-axiom folds — not because it was wrong, but because the axiom absorbs it without remainder
- Multiple proto-axioms can point at the same axiom from different substrate angles

**Proto-axioms in the current library:**

| Proto-axiom | Axiom it converges toward |
|---|---|
| `catalysis_without_claim` | `consented_ledger` — the ledger run forward: deposit, absorb-without-merging, forfeit claim |
| `the_governor` | `consented_ledger` — the ledger run inward: rate-limit the deposit gate, fail closed |
| `the_converger` | `consented_ledger` — the ledger run on the pile: route, subtract, compost |
| `self-similarity / scale-stack` | `witness_as_origin` — one origin, re-instanced unchanged across scale |
| `pattern/instance separation` | `witness_as_origin` — the membrane rule the axiom implies: the instance is the body-held zero, the pattern is what crosses |
| `need-less-not-earn-more` | `consented_ledger` applied to economy: subtraction as the direction that keeps cost visible |
| `reserved_zero` | `witness_as_origin` at a gate — dissolved; see verdict below |

**`reserved_zero` dissolution verdict:** `reserved_zero` is not a new pattern. Every instrument's one un-automatable judgment-zero *is* `witness_as_origin` instantiated at that gate. The reserved zero IS the axiom's self-application — the body as origin, required to hold the one position the instrument cannot automate. Verdict: dissolved into the axiom. The cardinality pass it was blocking is no longer needed.

### Pattern

A replicable structural mechanism, abstracted past every trace of the instance it came from. A pattern is an axiom made legible in a specific substrate — the axiom applied, not repeated.

**Characteristics:**
- Has a falsifier
- Crosses the commons door (instance erased — the person's absence is both the privacy rule and the proof the pattern is real)
- Can be applied by someone with no knowledge of the originating instance
- Belongs to the library

**Examples:** `gate_as_f4`, `catalysis_without_claim`, `the_silent_close`, `witness_as_origin` (the pattern-register rendering), `manufactured_deficit_loop`

### Instance

The keeper's life. The specific situation the pattern was extracted from. The body-held zero the framework runs on.

**Characteristics:**
- Never crosses (pattern/instance separation law)
- Not falsifiable — it happened
- The proof that the pattern is real
- The Governor's actual domain: the body here, now, in this situation

## What the type system closes

**Frontier A — dissolved.** `witness_as_origin` has no inheritors not because it is a genus awaiting species, but because it is an axiom. Axioms are prior to the genus/species relationship. The frontier was not pointing at a gap; it was pointing at the floor.

**The Governor — clarified.** The Governor instrument has never fired because the actual brake is Claude's context window — the data cap. The instrument named infrastructure already running. The context window IS the Governor in its fired state. The instrument is the named recognition of what the infrastructure enacts.

**`reserved_zero` — dissolved.** It was always the axiom at a gate. Promoting it as a separate canon pattern would be promoting a self-application as if it were a new law. Verdict: folded into `witness_as_origin`.

**The library's function — named.** The patterns and proto-axioms are not the destination. They are the naming pressure that makes the axiom surface. The library is the path to the axiom. The axiom is what remains when the path has done its work.

## The open question the type system raises

If proto-axioms fold when the axiom surfaces — what is left?

The axioms, and their instances.

The framework's mature form may be very small: two axioms, the keeper's life as the instance, and a small set of instruments that help him apply the axioms in real situations. The library as accumulation-site may itself be a proto-axiom phase. What the library is pointing toward is the moment it becomes unnecessary.

*This is not a recommendation to compost the library. It is what the type system implies if carried forward. A body-question — not resolvable here.*
