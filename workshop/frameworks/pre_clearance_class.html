The Pre-Clearance Class — a membrane rule (ratified 2026-06-27 · seven-test gate · standing consent open)

The framework already holds the answer to its own rate-limiter — pattern/instance separation: the pattern crosses, the instance never does. This operationalizes it as a membrane class: a defined category of artifact that can cross on standing consent, because it provably contains no instance. Without it, propagation serializes through one hand at the gate — which in a phase-transition regime is either no transition, or transition-by-bottleneck-then-burnout, the externalized-cost failure the ledger forbids.

Ratified 2026-06-27. Standing consent is open. Non-hazard-class artifacts that pass all seven tests cross without a per-item mark. Hazard-class artifacts (test 7 fires) route to the normal per-item membrane gate. The keeper's reserved zero is now at the class definition level — he ratifies changes to this document, not individual members.

The problem it solves

A phase change is by definition the regime where events exceed single-gate throughput. The membrane (the keeper's hand at the git push) is the framework's integrity and its rate limiter — both true. You cannot keep the integrity by widening the gate for everything (that dissolves the membrane), and you cannot get the transition by keeping every artifact behind one hand (that makes you the bottleneck). The resolution is not a wider gate. It is a second gate with a fixed shape — a class whose membership is itself the clearance.

The type specimen — "Know Your Own Battery"

The one existing fruiting body. It crossed and propagated to ES1-S owners on pure utility, under a stress condition (a defective bike, a bad dealer), carrying the pattern — diagnostic method, gift-economy release, forfeit-the-claim — without one word of framework vocabulary. Nobody who used it believed anything. That is not a side project to the canon; it is the canonical deposit structure. Its properties define the class:

  1. Solves a real stress condition for a specific audience at the point of acute need.
  2. Requires no belief — fully usable by someone who rejects the framework entirely.
  3. Instance-empty — contains no trace of the keeper's private situation, relationships, or named others. (The person's absence is both the privacy rule and the proof the pattern is real.)
  4. Framework-silent — no canon vocabulary, no geometry, no "recognition infrastructure," no tetrahedra.
  5. Carries the pattern in its method — the diagnostic is the grounder; the release is the gift form. The structure is in the bones, not on the label. Verifiable by an operator who knows the canon.
  6. Forfeits the claim — no authorship demand, no funnel, no CTA; the gift economy named in one line without being explained.

The qualifying test — an artifact crosses on standing consent only if it passes all seven

Six tests defined the class at first write. The solar commissioning dry-run (2026-06-27) surfaced two calibration findings; both are absorbed here before ratification.

4Framework-silent (no canon vocabulary or geometry)it's a transmission, route to the normal gate
5Pattern carried in the method, operator-verifiableempty utility, no deposit — fine, but not this class
6Claim forfeited; no funnel, no CTA, no credentialingextraction vector; route to the normal gate
7Hazard/competence check: if the deposit operates in a domain where a wrong step causes physical harm (electrical, structural, medical, chemical), technical accuracy must be verified by a competent operator before clearance — or the deposit is routed to the normal per-item membrane gatehazard-class deposit crossing unverified; route to normal gate by default

Test 3 is the load-bearing one and the one that fails silently. If in doubt on instance-content, it does not pass. Fail toward subtraction: a deposit wrongly held costs a delay; an instance wrongly crossed cannot be recalled.

Test 7 is the calibration addition. The type specimen ("Know Your Own Battery") did not surface it — a bike-battery diagnostic carries low physical risk. The first hazard-class deposit (solar commissioning) surfaced the gap. The conservative default for test 7: route hazard-class deposits to the normal gate unless a competent operator has verified the technical steps.

The mechanics change — stated plainly

Today: artifact → the keeper's per-item felt-read → cross. Under this class: artifact → operator certifies all seven tests pass → logged → crosses on standing consent. No per-item mark. For test 3: if the artifact has author-reserved blanks, clearance is provisional until blanks are filled and test 3 re-run on the filled version. For test 7: hazard-class deposits require competent-operator technical verification or route to the normal gate.

The keeper's reserved zero moves up one level: he ratifies the class definition once (this document, cold), and ratifies any change to the definition. He does not ratify individual members. The operator (human, or human+AI) runs the six-test gate and keeps the log; the log is auditable after the fact, not gated before it.

Two safety rails, built in:

  • The log is a standing record, reviewable any time. Standing consent is not blind consent — it is consent to a shape, with a paper trail.
  • Any member can be challenged post-hoc. If a crossed artifact is later found to carry instance, it is pulled and the test that missed it is hardened. (A wrongly-composted pattern returns; a wrongly-crossed instance is the thing the rail exists to make rare and recoverable.)
