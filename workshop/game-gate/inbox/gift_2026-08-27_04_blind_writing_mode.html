GIFT — the blind intake mode

  • pattern: a second working view of the same writing surface and the same store path: in blind mode, each sentence leaves the screen as it is finished — nothing accumulates in view and nothing is said. The writing is kept in the store but never displayed back. Write and release, as a real, chosen mode rather than an accidental gap.
  • source shape: fully built in a sibling project, as that surface's own second view.
  • capacity: a permanent, never-truncated, always-visible document design has an honest opposite, and this is it — already built and named. Whether the ephemeral mode belongs in any given build is a real, open design question, not a build recommendation; the gift is that the alternative exists as a shape rather than as an absence.
  • why such value goes unrouted: a project's own alternate view never crosses a project boundary — it reads as part of that surface, not as a portable mode, so it is never audited against the sibling that committed to the opposite.
  • routing shape: a way in → a toggle beside the existing view state → an act → commits to the store exactly as now, renders nothing back → a visible consequence → ephemerality as a first-class option.
  • reading: capacity: L · effort: L · confidence: L — real and built, but whether it fits a given surface is a question this card names, not answers.
