# INBOX — the unrouted-gifts pipeline, as pattern

How latent capacity in past builds is found, carded, and routed — the shape of the pipeline, not the record of any one run.

## The gate rule

Routing a gift card — committing its capacity into a live file — is not complete until the same admission call every other builder change goes through runs for it, with the gift's own id, what it made possible, and where it landed. A gift pipeline that lands work by direct commit while the mark ledger stays silent has a real gap; the fix is not a new mechanism but pointing the pipeline at the one that already exists.

## The finding shape

A cheap lens heuristic sweeps the library roots and names candidates; the candidates that matter are then opened and read in full, never routed on a header score. Each surviving capacity is checked against the live build before a card is written. Some roots come back byte-identical to the live tree (already received); some come back dry — every portable discipline they carry turns out already built, and more developed, inside the receiving project itself. Dry is a real finding, recorded, not a failure.

## The disposition grammar

Every card ends in exactly one of a small set of honest states:

- **routed** — built into the live surface, admitted through the gate, with what landed named.
- **routed with correction** — the port survived a sweep or an audit that changed its shape (a proxy check replaced by the right check; a toggle re-scoped to a read-only list where nothing was actually conditional). The correction is part of the record.
- **partially routed** — the smallest honest form built and verified; the fuller mechanic left explicitly unbuilt and undecided.
- **not routed, correctly so** — the capacity is real but its precondition is not built. Building it would mean inventing the precondition, which is a separate decision, not a routing. These cards wait, on their own stated terms.
- **not routed, corrected** — a proposed cheap route did not survive contact with the real code; the card is returned to the waiting state rather than forced through the wrong site.

The recurring shape across every unrouted card: a real, proven pattern with no current feature for it to attach to — left that way rather than inventing a consumer to force it in.
