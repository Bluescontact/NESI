# GIFT — set it down, the refusal as a real, equal third option

- **pattern:** every routing choice offers exactly three doors with equal visual and functional weight: send it here, send it there, or set it down and send it nowhere. The third is a first-class act — it closes the surface and changes nothing, and the almost-nothing is the point: a hand that sets a thing down has finished with it. It is not framed as a cancel, a skip, a "not yet," or a way out of deciding — it is one of the things the surface does.
- **source shape:** built as an amendment to a two-outputs design in an earlier build, minutes after the two-output version was written — the world needed a refusal.
- **capacity:** any choice surface that routes a person's material somewhere implies, or defaults to, an act. This pattern gives non-action a real, named, equally weighted door on the same menu — not a lesser default, not silence, but a labeled third option with its own key.
- **why such value goes unrouted:** a pattern implemented as one function inside one node is never named as a general UI law; and the pattern has a real precondition — two or more genuine destinations must already exist before a "nowhere" can be equally weighted. Relabeling a cancel button on a confirm/cancel binary does not route it; that restyles a cancel, it does not build a third door.
- **routing shape:** a way in → the next surface offering a real multi-destination choice → an act → a third, equally styled option that does nothing but close the surface → a visible consequence → doing nothing as a real answer, not an absence.
- **reading:** capacity: M · effort: L · confidence: M
