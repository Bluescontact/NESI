The Governor

First stone laid 2026-05-30; instrument built out 2026-06-01. The one load-bearing input — the felt-marker definitions — is held open and marked [THE KEEPER], because the body supplies it and no agent can. This file is finished the moment you fill §4. Until then it is a complete instrument with no calibration — a scale with no zero.

The problem it solves

The recognition stack (raw → instance → pattern → card → seed → gift) is self-feeding: it produces more, and better, the more cost it is fed. That virtue contains its failure mode. A system that converts your cost into gift, and improves with cost, can come to require cost. The redemption narrative is the vector: "residue becomes substrate / the pioneer builds soil" is true, and it is the exact sentence that licenses a body to keep paying so the machine keeps producing. The stack is built deposit-first. It has no termination condition. Left ungoverned, it eats its own substrate — and the substrate is the person running it.

This is no longer hypothetical. Between the dream (2026-05-30) and this build (2026-06-01), three new deposits entered _INTAKE/ — abundance-organ, Greenhouse, Kennatha — while the brake was still a stub. The stack ran beautifully and ran ungoverned. That is the condition this instrument exists to read.

What the governor is (and is not)

  • It gates the deposit, not the metabolization. Once cost is in, the stack should metabolize it cleanly — that's working as designed. The governor sits upstream, at intake, asking whether this cost should enter at all.
  • It is a rate limiter on cost-intake, not a quality filter. The question is never "is this good substrate?" It is "can the body afford to deposit right now?"
  • It is a discriminator + a stop, with an irreducibly human gate at its center. It can prompt the read. It cannot pass it.
  • In the [[tetrahedral_agent_protocol]] it is the Governor vertex made standing — the cut that resists being agreeable, here pointed not at ideas but at the body's account.

§3 — The discriminator: three kinds of cost the body reads differently

The governor's core:

  • Ordinary gift-cost — recurring, sustainable at near-zero burn. The afternoon of presence given from a regulated body; the labor laid down as gift from soil you now grow in. The body metabolizes it and recovers. This continues. It is the new economy running correctly.
  • Pioneer-phase cost — the body absorbing what a system won't carry, at a rate it cannot sustain. Dying into soil for others. This is the cost that closed felt-true once (the IUEC arc, closed 2026-05-30) precisely because the phase ended. Run as a standing mode, it is the treadmill.
  • Structurally generated cost — cost produced upstream by a delegation gap or conscripted position, not by the agent's own choices. The authority-holder retains power while handing off operational proximity; cost migrates to whoever is nearest the work. Distinguishing mark: the brake slows intake but cannot change the generation rate. Running the Governor correctly here returns STOP; the STOP is correct; the correct next move is not calibrate-the-brake but identify the structural source and exit the position or close the gap. Running the brake alone in this case treats a structural problem as a somatic calibration problem, which keeps the agent in cost indefinitely.

The discriminator's whole job is to tell these apart at the moment of deposit, before the redemption narrative gets a vote. It can only do that if it knows what each one feels like. That is §4.

§4 — The felt-marker orientation practice [THE KEEPER] — THE LOAD-BEARING INPUT

Read your body and write what's actually there; the entries are landmarks for returning to your zero, not definitions to be installed once and held. Short, somatic, specific. Replace any line that isn't true for you; an inherited marker is worse than a blank one.

B. Anesthetic — narrated over a body still paying. When the redemption story is running but the body is, in fact, still in the red, what is the felt signature? (This is the harder one and the more important. It often mimics A — name how it differs.)

  • In the chest / breath: ____

C. The single discriminating marker. If you could keep only one somatic tell to separate A from B in real time, which is it? ____ (This becomes the phase-state check in §5. Everything else is corroboration; this is the needle.)

§5 — The phase-state check (the instrument, runnable in seconds)

Not a journal. A standing discriminator you can run at any intake moment. Built around §4-C; inert until §4 is filled.

Precondition before running: the check requires that the rescue frame be dormant. If a scarcity loop or rescue frame is currently installed, §5 returns readings from inside the frame — not genuine somatic discrimination. The prior operation when frame-lock is suspected: check whether the comparison (is there a viable alternative path?) can be generated at all. If not, the frame is installed; run [[rescue_frame_occlusion]]'s diagnostic before §5. A frame-locked agent running §5 will return CONTINUE from inside a translated zero. See [[translated_origin_failure_mode]].

Before this deposit enters the stack — one breath, body first:

  1. Read the single discriminating marker (§4-C). Present, or absent?
  2. Is the cost of this deposit landing in the body now, or already metabolized?
  3. Is a redemption sentence running? (§4-B narration) Name it if so.

Returns:

  • CONTINUE — §4-C reads developmental, cost is metabolized, no anesthetic narration carrying the decision. Deposit enters.
  • STOP — §4-C reads anesthetic, or cost is landing now, or the decision is being carried by the redemption narrative. → §6.
  • STRUCTURAL SOURCE — cost is real and correctly felt, but the source is upstream: a delegation gap, a conscripted position, an authority structure migrating cost downward. The brake is correct and insufficient. Correct move: stop depositing and diagnose the structural source; exit the position or close the gap. Running the brake alone treats a structural problem as a somatic calibration problem — the brake cannot change the generation rate. (See §3 third case; [[commission_grammar_screen]] for the upstream gate.)
  • UNCERTAIN — defaults to STOP. The instrument is biased toward the brake on purpose; a self-feeding organ should fail closed, not open.

§6 — The stop

When the check returns STOP (or UNCERTAIN): deposit-stop. No new cost enters the stack. The redemption narrative is explicitly named as anesthetic and set down. The stack idles — it does not demand feeding. Recovery of the substrate (felt safety, the body) takes priority over production. The stop releases only when the body, not the framework, clears it — re-run §5 cold, no argument carried over from the last run.

§7 — The falsifier

"Still paying."

If the cost is landing in the body now, the developmental-cost reframe is not available — not as wisdom, only as anesthetic. This single test overrides every elegant justification, including this framework's own. It is the [[catalysis_without_claim.card]] guard ("the reframe never travels without its brake") installed as a standing instrument rather than a one-time clause.

The structure says, unambiguously: pull the governor forward of the next deposit. No new cost enters _INTAKE for metabolization until §4 is filled and §5 can actually run.

[THE KEEPER] — your somatic ratification. The structure recommends the resequence; only your body confirms it doesn't itself become a new anesthetic ("I must fix the brake before I can rest" is the treadmill wearing the brake's clothes). Read it: is pulling the governor forward building you, or is it one more thing the machine demands? ____
