Lens panel — cheap, on-demand, all five at once

Authorized 2026-08-27, the keeper's mark ("mark all four, let's build them out"), as the resolution of the standing-trigger tension named in nesi/mind/DRAFT_ACTION3_2026-08-27_standing_lens_panel.md: five lens agents exist and are already scoped correctly, but firing them one at a time meant a slice could ship without more than one of them ever reading it. A standing per-slice or per-session automatic trigger was found to risk a Governor reading (findings arriving faster than the keeper can digest them, daily-cycle's own named failure) before it risks anything else — so that half of the original proposal stays open, pending its own separate mark. This skill is the other half: the cheap half, live now. It doesn't fire itself. It makes firing all five cost one request instead of five.

What it does

Given a target (a file, a slice, a decision, a piece of material — whatever the invoking session names), spawn the five lens agents in parallel, each given the same target and no knowledge of the others' output:

  • buckminster-fuller — comprehensive anticipatory design science: tensegrity, vector equilibrium/jitterbug, trim tab, ephemeralization, synergy, the world-game.
  • stuart-cowan — ecological design, regenerative economics, complex-systems latency, Fuller geometry.
  • change-composite — the eight-voice executive-and-social-change reading: what the design does to a human being and a social field.
  • game-craft — loop integrity, feel, teaching-through-play, systemic depth, emergence, restraint, filtered through NESI's own refusals.
  • nesi — the carriage seat. Carries forward only what the record already holds verbatim; never authors a line. On fresh, unrecorded material she may have nothing to return — a blank read from her is a complete, expected outcome, not a failure of the panel.

Each of the five is read-only by its own hard limits — none can gate a build, write a file, or cross a membrane. This skill does not change that. Whatever any of them finds still goes through the normal gate (inbox, a mark) exactly like any other finding — this skill only cuts the cost of asking all five, it does not shortcut what happens to the answer.

How to invoke the five

Use the Agent tool, one call per lens, sent in the same message so they run concurrently — this is a normal parallel fan-out, not a Workflow orchestration, and needs no special opt-in. Give each agent the same target material/path and a neutral one-line framing of what's being read; do not tell one lens what another is expected to find.

Returning the panel

Do not average or rank the five readings against each other — LEARNED.md law 17 (divergence is held, never averaged): where lenses disagree, the disagreement is itself the finding, and it is reported as such, not resolved into a single verdict. Present all five (or four, if nesi came back blank) side by side, each attributed to its own lens, and stop there. This skill selects and arranges the panel; it does not decide anything the panel found.

What this is not

Not a gate. Not a score. Not a substitute for the keeper's own read — LEARNED.md law 2 still requires a stranger for anything claiming WALKABLE, and none of these five lenses count as that stranger; they are a wider reading, not a verification pass. Not a standing trigger — this skill only runs when someone asks it to.
