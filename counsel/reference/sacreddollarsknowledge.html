1 · The Gift Model Framework

Source: project description ("The Gift Model: A Framework for Transformative Currency")

"How might we transform ordinary currency into carriers of inner awakening, creating a network of meaningful exchanges that ripple through individual consciousness and collective systems?"

The Physical Artifact

A dollar bill becomes a multi-layered artifact of meaning. A white sticker carries a visible affirmation — accessible, action-oriented, an invitation to first engagement. A clear sticker carries a hidden affirmation, a deeper truth revealed only when the bill is held up to light. A handwritten personal signature commits the giver to the gift economy, an invitation asks the recipient to consider their own gifts, and a QR code opens deeper engagement.

Visible truth→ Backlit revelation→ Personal signature→ Invitation to give→ QR / deeper journey

3 · Affirmation Architecture

The content system behind every sticker set

The full vision is 96 paired affirmations organized as 8 categories of 12 pairs, forming a complete cycle of transformation. Each pair works on multiple levels:

Visible

Accessible, action-oriented statements that invite initial engagement — printed on the white sticker.

Hidden

Deeper truths revealed through intentional discovery — printed on the clear sticker, seen through backlighting.

Progressive

Building from self-discovery toward spiritual connection across the sequence.

Fractal

Each pair contains the essence of the whole journey.

Two named categories exist so far — Trust & Presence and Connection & Resonance — each developed as a 24-affirmation sticker set. Trust & Presence also has a complete set of 24 visible→hidden pairs and a print layout organized in two movements (Foundation and Deepening). An earlier 20-affirmation "I"-statement set predates the "Your…" voice.

8 · Production Specifications

Sources: "Affirmation Sticker Text Guidelines.md" and the print-sheet HTML layouts

Typography

Font
Bree Serif (Google Fonts)
Size
14px (guidelines) / 16px (layouts)
Line height
1.2
Letter spacing
0.03em (0.08em on landscape sheets)
Weight
500 medium / 600 on sheets
Line length
~40–45 chars max

Writing Guidelines (original "I" voice)

  1. Start each affirmation with "I" or "My" for personal connection
  2. Keep statements in present tense
  3. Use positive affirmations (avoid negatives)
  4. One clear statement per sticker
  5. Length: ideally 20–40 characters for optimal readability (49 chars is the observed maximum)

Format patterns

I am [quality/state].
I [verb] with [noun].
I [verb] my [noun].
My [noun] is [quality].

Print Layouts

Portrait sheet (original set)

  • Letter, 8.5" × 11" portrait
  • Grid: 2 columns × 10 rows
  • Sticker: 4" × 1", 0.12in × 0.15in padding
  • Page padding: 0.5in top/bottom, 0.25in sides
  • Number bottom-right, 10px gray
  • Dashed borders as cut guides

Landscape sheets (category sets)

  • Letter landscape, 11" × 8.5", print on sticker paper
  • Grid: 2 columns (5.25in) × 6 rows (1.29in), 0.1in gap
  • Page padding: 0.375in / 0.25in; 12 stickers per page, 24 per set
  • Each sticker: affirmation (2 lines, centered left-of-middle), number bottom-left ("n of 24"), category tagline bottom-right, 0.6in QR placeholder right-center
  • Instructions block hidden on print; page-break between sheets

Template Substitution Workflow

  1. Copy the HTML template
  2. Replace the text between <div class="sticker"> and the number span
  3. Keep the number spans unchanged
  4. Test print to ensure text fits within sticker boundaries

Open threads
