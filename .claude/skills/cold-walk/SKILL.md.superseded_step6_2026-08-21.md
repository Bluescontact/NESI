## Why it was wrong

`LEARNED.md` law 3 ("VERIFICATION IS PRESTRESS, NOT IDENTITY"), reframed by
Kevin's own mark 2026-08-18 — one day *before* this skill's own 08-19
precedent — already ruled out exactly this move: "a check holds a load
because it is structural and general — re-evaluating, independent of who
built it — never because a different hand ran it." A second Claude Code
agent invocation is a different hand, not a different kind of check. The
08-19 precedent this step cited as "the shape to repeat" was itself an
instance of the identity-swap law 3 exists to close — the agent that
received the transcript that day was still the same model grading the same
model's own work, dressed as a handoff. Named as debris/leakage a second
time, 2026-08-21, by Kevin — law 2 (the ancestor of law 3) had already fired
twice, one day apart, on 2026-08-12; this was the same leak recurring again,
inside the very skill built to prevent it.

## The 2026-08-21 correction (now live in `SKILL.md`)

Only a human who didn't write the code may write WALKABLE. A second read run
through this same tool ecosystem — another agent call, another session,
under whatever name — is not independent verification; it is the same hand
in a different glove. That kind of second read may still run the structural
pre-check (step 4) and produce a second UNWITNESSED read, but it may never
write WALKABLE itself.
