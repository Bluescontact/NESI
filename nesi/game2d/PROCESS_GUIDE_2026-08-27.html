1 · The page, today

index.html — NESI's entry point since 2026-08-26

You type. A finished sentence — ended by . ! ? … — drops into a day-grouped document that keeps every sentence in full. Two structural facts, and only two, decide where it lands and how large it renders: how long your hands were idle before you started typing it, and how many words it is. Nothing reads what a sentence says.

It replaced a twelve-seat door built on solid.js geometry — kept whole at index.html.backup_pre-lattice-entry_2026-08-26.html, not deleted, superseded because it was still "a bench of links leading out," Kevin's own naming of the shape that stopped working.

"menus and tabs and functions that route nowhere... I have no reason to write anything anywhere." Kevin, lattice.html's header, the day before the reclaim

3 · The tetra dreams — five shapes, all real, all read-only

Kevin's framing: "each sentence as a pebble, each word as a node... map the 6 relationships at any point in the system, built a tetra an object"

All five read the same localStorage["nesi.thepage"] the writing page fills. None write to it (Dream B keeps its own key).

A — the four-pick lens holds at tested scale

tetra_dream_A_fourpick.html — pick four sentences, render the six edges between them. Audit fixed a declared-edge collision and a centroid-vertex layout bug. Near-pairs computation is O(n²) — fine now, would need a window at real scale (months of daily writing).

B — pebbles and stones value proposition unresolved

tetra_dream_B_pebbles.html — group sentences into a named "stone"; four stones read the same tetra. Hinge detection was a fake stub (nearly everything read as a hinge) — fixed by porting the real cut-vertex algorithm. Still open: does grouping earn its complexity over Dream A's simpler four-pick, and a sentence can currently belong to more than one stone.

C — the standing tetra stale "now" fixed

tetra_dream_C_standing.html — a companion window always showing the tetrahedron around wherever writing currently is. Originally "now" meant only the last sentence written, going stale during rereading. Fixed: index.html now writes an attention record after 1.5s hover; Dream C prefers a recent one once writing has paused.

D — the typed matrix built, verified against seeded data

tetra_dream_D_matrix.html — answers the strongest outside objection: a tetrahedron forces all six edges to look identical (undirected, symmetric), and chain/declared are directional. A 4×4 matrix has a place for pair facts off-diagonal and node facts (hinge) on the diagonal.

E — the derived gifts built, ceiling named

tetra_dream_E_gifts.html — pick one anchor sentence; the other three vertices are derived (chain gift, near gift, declared gift), never picked. Ground finding: triple illumination is not reachable by this construction — chain and near can never derive the same gift, so the fourth face's ceiling is two-lens overlap, never three. Named as a real limit of this construction, not of the tetrahedron in general.

The boundary named, not a refutation: sourced research (Pennebaker's LIWC, the Forer/Barnum effect, pause-timing confounds, forensic stylometry) shows pronoun-adjacency patterns are genuinely diagnostic material. "Measuring only structure, never meaning" is true of the algorithm and was never sufficient on its own — the artifact a words or categories ground produces carries the same weight as any diagnostically-loaded writing record. The build already satisfies this in practice (no export, no sync, no network call, enforced by refusal_check) — the gap was that this was never stated. Fixed by adding an honest note to both grounds.

6 · What's genuinely open — decisions available today

  • Which shape develops further — lens, hierarchy, ambient companion, matrix, or gift-derivation — is Kevin's call; they may not need to converge into one.
  • Dream B's core value proposition: does grouping add enough real relationship signal to justify its own storage key and UI, over Dream A's simpler four-pick?
  • WINDOW_DAYS=21 and the 1.5s dwell threshold are first guesses — real numbers to tune once this gets used for months, not weeks.
  • Whether a different derivation of the three gifts (Dream E) could reach triple illumination, or whether §4's answer (drop the shape) is the right one.
  • The words ground's follows-concordance is intra-sentence adjacency, a different shape from Kevin's original "each word as a tetra vertex" framing — whether that framing still wants building, separately, is open.
  • The interest-weighted-selection idea (surfacing structurally meaningful fours instead of nearest/newest) is named in the outside-model thread, not built in any shape yet.
  • Whether categories belongs permanently in the writer's own margin, or reads as a debugging/audit view that landed at the same altitude as the others.
