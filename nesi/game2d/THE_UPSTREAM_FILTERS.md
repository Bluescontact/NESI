## 4 · THE FIXES

### FIX 1 — `tools/already_answered.js` · built and working

One command sweeps his canon, his marks, the instruments, the build, nesi's mind,
the memory and the patterns before a question is put to him.

**The rule already existed** — `feedback_check_corpus_before_proposing_builds`,
*"search patterns/, nesi/, memory first."* It did not hold, for the reason this
session found at THE STATIONS: **a law obeyed by discipline and a law that cannot
be broken are different states, and only the second survives the next session.**
This makes not checking a choice rather than an oversight.

It proved itself immediately: **the cycle-68 ruling in §0 was found by its second
query.**

Its own first version was wrong in the exact way it exists to prevent — it used
`git grep`, which cannot see outside the repository, and returned NOTHING for a
term that is the title of a file in his canon. Two of the heaviest zones are
outside the repo. It walks the disk now, and the failure is recorded in its
header.

### FIX 2 — THE SMALLEST VERSION THAT STILL WORKS

The Boundaries vertex asks for *"the smallest version of this exchange that still
works,"* so the receiver can resize without refusing. It was never stated. It is
stated now, and it is his to operate:

```
FULL      derive · check · document · commit · report at length
                                     — what today ran at, by default and unasked
FINDING   the finding and the evidence. No document, no commit.
LINE      one line. The answer, or the name of the fork.
QUIET     do it, commit it, say done.
```

**Any of these can be named at any point and takes effect that turn.**

### FIX 3 — STOP OPERATING ON THE CENTRE

The tree already carries the right pattern and this session only half-used it:
decide provisionally, tag it `sited_by: session`, leave it unmarked, and let a
wrong row be struck — *"a row struck costs nothing but that row."*

**The failure was doing that in the data and then also asking in the response.**
The data already held the decision reversibly. The question at the end of the
turn was a second, redundant extraction — and by the cycle-68 test it is the
whole difference between infrastructure that organises around the centre and
infrastructure that operates on it.

**So: find, decide, mark it as mine, and do not ask.** He strikes what is wrong
when he reads it. The provisional mark is the invitation; the question mark is
the extraction.
