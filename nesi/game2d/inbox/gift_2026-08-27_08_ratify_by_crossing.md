# GIFT — confirm a connection by dragging it across a line, not by typing

- **title:** ratify by crossing, not by naming
- **what:** a real, working alternate gesture for turning a tentative relationship into a real one. Objects carry "proposed" edges (visual only, apply no force, just stretch and go slack). Drag the object physically across a named boundary line and the geometry itself decides: did the connecting line actually cross the seam during the drag? If yes, the edge ratifies — becomes real, starts pulling its other end like a spring. If the object crosses back, it reverts. No dialog, no typed label, no click-to-confirm — the gesture of carrying something across a line *is* the confirmation.
- **source:** `nesi/nesi_bench_v0/render.py:262-427` (the `pointerdown`/`pointermove`/`endDrag` handlers and `ratifyEdge`/`revertEdge`/`severEdge`), a real, runnable single-file HTML surface this Python module generates
- **when:** part of the nesi_bench_v0 project's Stage 3 work; the file's own header dates the geometric test to "v1 Sec 6"
- **quote:** *"does THIS edge's own connecting vector (not the object's box) cross X_GATE within the dragged object's current Y-bounds?"* — and on why: *"the spatial fact (a taut line where there was a slack one, or the line's absence) is the only acknowledgment"* — no "successfully crossed" toast, no praise, nothing but the line itself changing.
- **capacity:** `the_page`'s own "declare a connection" flow today is entirely textual — select a sentence, click "declare," pick a second sentence, type a label, click confirm. This organ shows a real, different, more embodied way to confirm the *same kind of fact* (two things are really related, not just near each other) — by moving one physically past the other, the way the world ground already lets you seat sentences by hand, or the filter ground already lets you sort motes by hand. It would sit naturally beside the existing text-declare flow, not replace it — the label still needs typing to say *what* the relationship is; this only offers a second way to say *that* one exists.
- **unrouted_because:** built for an entirely different tool (a staging-to-landing review bench for arbitrary objects, not sentences), never read against this project at all before this pass.
- **routing:** a way in → the relationship or world ground's own drag-to-arrange physics, already built → an act → while dragging a seated sentence, if it crosses near enough to another seated sentence's real position, offer the same staged-declare tray the text flow already uses, pre-filled and ready for a label, instead of requiring the click-through-panel path from scratch → a visible consequence → a second, physical route to the same real, hand-confirmed declaration the page already treats as the one place a writer's own judgment enters the structure.
- **reading:** capacity: M · effort: M · confidence: M — the geometric test itself (segment-crosses-line) is a few lines and cheap to port; deciding what "close enough to ratify" means for two dragged sentence-cards, rather than a fixed gate seam, is a real design choice this pass doesn't make for you.
