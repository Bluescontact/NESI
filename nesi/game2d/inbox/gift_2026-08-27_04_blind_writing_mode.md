# GIFT — a second, ephemeral intake mode, already built and named

- **title:** BLIND — write here, and it leaves
- **what:** a second working view of the same writing band and the same store path as the page's normal ("tiles") mode — in blind mode, each sentence leaves as it is finished and nothing accumulates on screen; nothing is shown, nothing is said.
- **source:** `nesi/world2d/scripts/writing_field.gd:2-20`
- **when:** predates this session; part of the same world2d project as the filters panel above
- **quote:** *"TWO VIEWS, both this same band and the same store path: blind — each sentence leaves as it is finished; nothing accumulates in view and nothing is said. tiles — each sentence its own tile on the table, grouped in written order."* — `writing_field.gd:14-17`
- **capacity:** the page's whole design commits to the opposite of this — permanent, never-truncated, always-visible (`KNOWLEDGE_the_page_and_the_tetra_2026-08-26.md` §1: "a day-grouped, never-truncated document"). This gift is not a fix for anything broken in that; it's a second, already-built mode naming the honest alternative — write and release, kept in the store but never displayed back. Whether that belongs anywhere in the current lattice is a real, open question, not a build recommendation.
- **unrouted_because:** it's the world2d project's own second view of its writing surface, never connected to `game2d`'s page at all — a genuinely different question from why the culling/garden organs above are unrouted (those were cut; this was simply never crossed over).
- **routing:** a way in → a toggle beside the page's existing view state → an act → sentences commit to the store exactly as now, but the visible document renders nothing back → a visible consequence → an ephemeral writing mode exists as a real, chosen option, not an accidental gap.
- **reading:** capacity: L · effort: L · confidence: L — the lowest-confidence card here; it's real and built, but whether it fits what the page has become is a design question this pass can name, not answer.
