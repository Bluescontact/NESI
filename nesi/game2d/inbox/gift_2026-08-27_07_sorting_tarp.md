# GIFT — see the shape of everything you've written, without reading a word of it

- **title:** the sorting tarp
- **what:** a real, fully-built 3D instrument — every piece of writing laid out at once on a worksurface, as an anonymous slab. A slab's footprint is how big the thing is; its thickness is how long it's sat there. No text, no label, no number, anywhere. One button gathers the pile — a real physical fold, corners lifting, cloth drawing in — and *stages* (never commits) a record of what was on it.
- **source:** `nesi/world3d/.walk/_snapshot/scripts/sorting_tarp.gd`, whole file (351 lines), quoted from its own header
- **when:** built 2026-08-06, on Kevin's own brief, quoted verbatim in the file itself
- **quote:** *"if each space has a worksurface and tools... if objects and their uses are apparent by shape and design rather than explanation... I'm trying to build a system where i dont need articulation.. I want to be able to hold everything all at once and have it outside of me so i can see its shape and walk through a space where i become visible to myself."* — this is the brief the file was built against, and it's the same brief behind two turns ago's "workshop" language, in his own words, from a different day.
- **capacity:** every ground `the_page` has built so far shows sentences as text — cards, matrices, mote-lists, all readable. This is the one real, built, working exception: a whole-corpus view that shows nothing but shape. Two real facts already privileged by this page (word count → size, idle-gap → age/thickness) map onto the tarp's own two facts (footprint, thickness) almost exactly as written, with zero translation needed for what each axis means.
- **unrouted_because:** built for a different project's own pile of staged intake objects (world3d's Bar/store), never checked against `the_page`'s sentence data at all until this pass.
- **routing:** a way in → a tenth ground, "tarp" → an act → every sentence renders as an anonymous rectangle (word count → size, idle-gap → shade/thickness, exactly the mapping this file already uses for two different facts), laid out once, deterministically, so the same pile reads the same way twice → a visible consequence → for the first time, a way to see the whole shape of what's been written without any of it being legible — the literal answer to "hold everything all at once... see its shape," built once already, never for this data.
- **reading:** capacity: H · effort: M · confidence: H — the layout math (`_lay_out()`) is a straightforward grid-pack, already deterministic and already proven; the 3D fold animation is decorative and can be dropped or simplified to a CSS transition without losing what the brief actually asked for.
