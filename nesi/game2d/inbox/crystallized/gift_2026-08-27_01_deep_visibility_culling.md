# GIFT — visibility culling as refusal-to-draw

- **pattern:** geometry outside the visible volume is never submitted for drawing — not drawn dark, not drawn small, never submitted at all. A flat cutoff refusal-to-draw, not a distance check run every frame.
- **source shape:** found in an earlier build's rendering layer, cut whole in a later full rewrite and kept in compost.
- **capacity:** a working answer to a scaling gap a corpus has already named and left open — a growing document stays responsive at months of accumulation because off-viewport elements are skipped at draw time rather than measured every frame.
- **why such value goes unrouted:** a full rewrite orphans working organs. When a build is rebuilt from scratch, an organ that was correct can be cut with the surface it lived in and never re-sited — not because it was wrong, but because the surface it survived in no longer exists.
- **routing shape:** a way in → the render loop already knows each element's position → an act → skip drawing anything outside the current viewport, as a flat cutoff → a visible consequence → responsiveness at scale that nothing previously guaranteed.
- **reading:** capacity: M · effort: L · confidence: H
