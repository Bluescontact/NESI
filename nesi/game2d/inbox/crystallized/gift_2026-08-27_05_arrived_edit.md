# GIFT — the arrived edit

- **pattern:** when a piece of writing can be changed from more than one face of a system, the original surface does not silently update. The edit appears next to the original, held, named in words as well as colour, and is taken only by a deliberate click on its own tile — never by a rule. Not a merge, not an overwrite: a proposal shown arrived and held until the writer's own act makes it real.
- **source shape:** fully built in a sibling project's multi-face build of the same writing surface.
- **capacity:** the honest answer to a fork every single-writer surface eventually faces — a second write-in point (an edit flow, a merge from another device). The choice is silent overwrite vs. a held proposal, and this pattern is the built form of the second, the same discipline as "the hand does the separating" applied to change over time.
- **why such value goes unrouted:** the capacity is real but its precondition is not built — the receiving surface has no editing at all yet, so there is nothing for the pattern to attach to. Correctly unrouted: building it would mean inventing the precondition, which is a separate decision, not a routing.
- **routing shape:** a way in → the day a second write-in point exists → an act → write the change to a held field and render it beside the original, unapplied → a visible consequence → nothing changes without the hand's own click.
- **reading:** capacity: M · effort: M · confidence: L — proven code, gated behind an unbuilt feature; worth remembering the day editing gets proposed.
