# GIFT — the case, a hand-openable panel that proves what's actually happening

- **title:** the case — a hand-openable panel that proves what's actually happening
- **what:** a TAB-toggled overlay that suspends the world and shows two things: a live instrument row (last few localStorage reads/writes, whether any model call or network request has ever fired — both start and stay at "no call"/"no request" because none exist), and a per-view CONSTRAINTS registry — every refusal/boundary active at the current face, each with a `says` line and a `keeps` line naming what it protects, each individually switchable off by a click, with `mine` boundaries (ones the build introduced) marked apart from `his` (ones Kevin set).
- **source:** `nesi/game2d/_compost/ascent_2026-08-21_pre-rebuild.html:574-624` (CONSTRAINTS, `bound()`, `boundsHere()`, `unbind()`) and `:2794-2905` (CASE, `op()`, `drawCase()`, `boundsClick()`) — corrected 2026-08-27; the original single range `2782-2905` covered only the second cluster and missed CONSTRAINTS/`bound()`/`boundsHere()`/`unbind()`, which sit over 2,000 lines earlier in the file. Line numbers re-verified directly against the source file, not re-derived from the prior citation. See `nesi/mind/VE24_RELATIONSHIPS_2026-08-27.html`, "Newly Resolved #4," and item 3 of `nesi/mind/DRAFT_LENS_PANEL_VE24_2026-08-27_preflight_manifest.md`.
- **when:** CASE opened as a mode 2026-08-14; the no-machine-sort/no-call constraints registered 2026-08-17 on Kevin's F4 mark; CONSTRAINTS array present at composting 2026-08-21
- **quote:** *"Opening the case now SUSPENDS THE WORLD. You are looking at the machine or you are playing it, never both... It is closed until a hand presses TAB, it costs nothing to open, and nothing in the world moves while it is."* And on the boundary panel: *"Each line is a switch. Click it and the boundary is off, in your store, immediately, and the world runs without it... Nothing here is a number and nothing here is about you."*
- **capacity:** `the_page` currently proves its refusals only by absence — a player has to take on faith that nothing calls a model or the network, and the boundaries this project's own `CLAUDE.md` calls out as load-bearing ("the refusals in refusal_check and the boundaries in the constraint registry are lints and container edges") are enforced invisibly, never shown to the hand that's inside them. This mechanic makes both visible and inspectable from inside the game itself, and hands the switch to the player rather than leaving it as a build-time-only guarantee.
- **unrouted_because:** dropped in the ascent.html rebuild along with the whole canvas draw-loop it depended on (`drawCase`/`drawBounds` are canvas 2D calls, hooked into the old per-frame `draw()`); its sibling static-analysis lint, `tools/retired/constraint_lint.js`, was retired in the same pass and the concept never got reattached to the current SVG-render ascent.html or to index.html.
- **routing:** a way in → a TAB key handler in the current `render()`/keydown path → an act → render an SVG (or DOM) equivalent panel listing the constraint set relevant to `view`/`cur`, each toggleable into a stored `S.off` array, plus a small live log of the page's own localStorage/`persist()` calls → a visible consequence → a player can open the case at any seat, see for themselves that nothing calls out and nothing hides, and can name and lift any one boundary rather than trusting an unseen one.
- **reading:** capacity: H · effort: M · confidence: M
