# GIFT — an edit shown, never applied, until the hand takes it

- **title:** the arrived edit
- **what:** in a second, parallel Godot build of this same writing surface, a sentence can be reached and changed from more than one face of the app. When that happens, the *original* page does not silently update — the edit appears next to the original sentence, held, with a button that must be clicked before it becomes real there too.
- **source:** `nesi/world2d/scripts/writing_main.gd:184-219` (`_fill_sheet_body()`), quoting its own comment at line 70-77
- **when:** predates this session; part of the same world2d project the filter panel came from
- **quote:** *"An edit held on another face shows here attached to its sentence, named in words as well as colour, and is taken only on its tile — never by a rule."* And in the render loop itself: `held.text = "an edit arrived, held → " + ...`, with a button reading `"TAKE THE ARRIVED EDIT — it becomes the sentence here too."`
- **capacity:** `the_page` has no editing at all today — a sentence is written once, then only deletable. This organ answers a question the page hasn't had to ask yet: if a sentence could ever be changed (from this ground or a companion window like `tetra_dream_C_standing.html` was reaching toward), the honest shape isn't a silent overwrite — it's showing the change *arrived* and *held*, next to the original, until the writer's own click makes it real. A real answer to a real future fork, not a speculative one: this exact tension (silent overwrite vs. a held proposal) is the same shape law 5's "the hand does the separating" already insists on elsewhere in this build.
- **unrouted_because:** `the_page` doesn't have an editing surface for this to attach to yet — the capacity is real but its precondition isn't built.
- **routing:** a way in → the day `the_page` grows a second write-in point (an edit flow, a merge from another device, anything that could change an existing sentence) → an act → don't overwrite; write the change to a `held` field on the node and render it beside the original, unapplied → a visible consequence → nothing changes without the hand's own click, the same discipline every other ground in this build already holds.
- **reading:** capacity: M · effort: M · confidence: L — real and well-proven code, but gated behind a feature (editing) `the_page` doesn't have. Not buildable in isolation; worth remembering the day editing gets proposed.
