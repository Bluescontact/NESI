## The visible-refusal rule

**A seat's refusal to rule is a visible logged event, never a silent stall.**
If a dispatched agent declines to rule on a fork because its own hard limit
fires, that refusal gets logged to `BUILD_RECORD.md` by name — which agent,
which fork, what it said — and the session rules instead, naming that it did
so in the agent's place. The build never quietly proceeds as if the refusal
didn't happen.

itself. Also unchanged: every ruling made under this file is recorded in
`BUILD_RECORD.md` by name, so nothing is decided silently even though it's
no longer asked.
