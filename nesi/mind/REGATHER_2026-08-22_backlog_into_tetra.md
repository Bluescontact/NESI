# THE BACKLOG REGATHERED INTO A TETRA — 16 mind/ files, sorted by what they already are

*Asked in chat, 2026-08-22: "do a regather of nesi into a thread tetra," narrowed
in the asking to: gather the open mind/ backlog (the 2026-08-19/20/21 drafts,
extractions, gate reports, resyntheses this working tree was carrying) and read
it as a tetra — four vertices, not a flat list.*

**This is offered, not ruled.** Grouping sixteen files into four vertices is a
reading, the same status THE_TWIN_TETRA_AND_THE_TOOL_SETS_2026-08-07.md gives
its own divergent pass: derived, not Kevin's, and naming what the four *faces*
(the tools three vertices close into) would mean is explicitly his work, not a
session's. Nothing here is filed to a ledger and nothing overturns any mark
already sitting on these files.

---

## THE BOUNDARY APPLIED

Every file in the pile keeps its own ruled/unruled state exactly as it already
carries it — this pass changes no file's status. The grouping sorts by **what
kind of thing each file already is and what it's already talking to**, read
off its own content and cross-references, not assigned from outside.
