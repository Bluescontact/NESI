Two master reference documents at `Project Lab/SOURCE_LIBRARY.md` and `Project Lab/PATTERNS_AND_VOICE.md`. These are tools, not deployables — read before working at the tool layer.

**SOURCE_LIBRARY.md** (rewritten 2026-05-24 as 15-position tetrahedral index, supersedes the May 11 version). The library is now declared as ONE tetrahedron: 4 vertices + 6 edges + 4 faces + 1 volume = 15 structural positions. Every doc on the working surface declares which position it serves; docs that cannot declare are not on the surface.

The 15 positions:
- **V1 MAKING** (THE_BUILD), **V2 SEEING** (THE_PATTERN), **V3 GIVING** (THE_GIFT), **V4 HOLDING** (THE_ARCHITECTURE)
- **E1** *The build teaches the pattern* (MAKING parents SEEING) · **E2** *The build is the gift* (bilateral seam) · **E3** *The tool outlives the hand* (MAKING parents HOLDING) · **E4** *The pattern becomes the gift* (SEEING parents GIVING) · **E5** *The framework instruments itself* (SEEING parents HOLDING) · **E6** *Refusal builds the container* (GIVING parents HOLDING)
- **F1** theoretical/relational/architectural register · **F2 FENCED — DO NOT POPULATE** (structurally non-documentary; documents are SEEING's output, so a face that excludes SEEING cannot materialize as documents) · **F3** closed substrate / pre-gift incubation · **F4** ephemeral transmission
- **Vol** gift economy as operating system (Architecture_of_Coherence_Manuscript reaches for this)

New directory: `Project Lab/edges/{V1}-{V2}/` with `THE_EDGE.md` substrate file per edge. All six edges have substrate docs. F2 has `F2_FENCE.md` declaring do-not-populate.

The MAKING-constraint routes every edge that touches MAKING (E1, E2, E3) and face F1 — physical builds are the operational gate; edge names make this visible rather than hiding it.

**PATTERNS_AND_VOICE.md** — Master reference for new outputs. Two halves: structural patterns (tetrahedral organization, three-naming translation, layer model, succession arc, designed failure, closed loops, overbuild-at-core, refusal as design, substrate independence, diagnostic-not-moral, visible/hidden pairing, naming as structural move) + linguistic patterns (four registers — direct geometric / vulnerable somatic / structural recognition / applied diagnostic — recurring constructions like "Not X. Y." and "X isn't Y. It's Z.", triplets, catalogued refusals, geometric vocabulary, load-bearing phrases, anti-patterns).

**Why:** Substrate-before-artifact rule. The library compressed to the geometry the framework describes is the precondition for any downstream deployment.

**How to apply:** When drafting new material, read PATTERNS_AND_VOICE first to lock register. When mapping/navigating the library, read SOURCE_LIBRARY first — the 15-position index tells you which slot a doc serves. New work that cannot declare a position is not ready for the working surface; compost it, archive it, or write the missing edge / face / volume substrate first.
