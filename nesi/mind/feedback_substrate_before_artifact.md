Don't jump to building artifacts when the substrate is still mid-metabolization. The artifact is downstream of the tools. Work the tool layer first; let composting happen; the artifact emerges from mature substrate.

**Why:** 2026-05-11 — Claude produced a full site-build plan in response to "build this as a website." Kevin corrected: "slow down before we build anything... the tools and lens, and pattern recognition we've built in the files is being composted and metabolised to create this phase transition. Build the tools first... then we'll build the site." The substrate is mid-phase-transition; premature artifact construction would freeze the substrate at the wrong shape and contaminate what's trying to emerge.

**How to apply:** When Kevin gestures toward a deliverable, check whether the underlying tools have finished their work. If not, work at the tool layer — read the files, map what exists, identify which tools are mature vs. mid-form vs. stuck, refine, name what's emerging, audit, prune. Resist the pull to generate the artifact. Also resist generating *new* tools just because they sound good — the substrate is already composting; addition is usually the wrong move. The work is selection, refinement, and naming what's trying to come through. Site exists at oursharedgifts.org (GitHub Pages) — technical deployment is not the bottleneck; tool maturation is.
