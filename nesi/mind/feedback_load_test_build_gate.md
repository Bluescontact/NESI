Canon build-law, adopted 2026-07-23 (Kevin's mark, "Adopt the load-test build-law into canon"). Lives in `nesi/mind/PROTOCOLS.md` under "The Load-Test — the build-gate," so it boot-loads every session.

**The gate, run BEFORE building:** *If this disappeared tomorrow, would Kevin once again have to carry something in his own head? If no, don't build it.*

**Why:** NESI exists to remove load from its keeper without removing his authority. A build that adds a room / surface / organ but takes no burden off Kevin's body is architecture masquerading as progress. This is a build-gate (what deserves to exist), not a per-artifact truth-test (that's the falsifier line).

**How to apply:** run it before proposing or building anything. If a build passes no burden off Kevin, hold or drop it. The guard is non-negotiable and inherited from [[feedback_ai_never_self_limits]]: the load-test gates what gets BUILT, never how much Kevin gets — it subtracts candidate builds, never capacity, depth, or held material. Self-falsifier: if it never stops a build that would otherwise have shipped, it was ceremony.
