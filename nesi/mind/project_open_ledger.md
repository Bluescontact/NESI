The Open Ledger is the **data-model / schema view** of the village tool (same tool as `CIRCUIT_TOOL.md`, which is the circuit/UI view; OSG/[[project_dispatcher]] lineage). Kevin named it 2026-06-21: *"it records everything that circulates and computes nothing that is owed."* The gift frame is enforced by **structural incapacity** — debt is not prohibited, it is *unrepresentable*, because there is no field for it. A frame held by instruction breaks when the instructor leaves; a frame held by a missing field holds in any hands.

Five vertebrae = five missing fields: (1) no counterparty/recipient → **barter** unrepresentable; (2) no numeric value, `weight` is qualitative text → **marketplace** unrepresentable; (3) no responses/declines table → **obligation-by-visibility** unrepresentable; (4) `contact` carries only reach, no role → the **"needy person"** unrepresentable; (5) no claim/obligation table → the **contract** unrepresentable. The seam: **shows the cost** (`weight`, legible — the Costed Handoff) and **hides the debt** (no balance computed). The one limit it cannot close: whether a gift was *felt* as gift or as extraction — that lives in the **gathering** (a first-class kind), not the tool; the gathering is both felt-extraction detector and debt-dissolver.

Built by Claude (pre-gate) at `open_ledger/`: `SCHEMA.sql` (SQLite), `schema.ts` (incapacities as compile errors), `THE_OPEN_LEDGER.md` (spec), `demo.html` (interactive "holds in a stranger's hands" demo — verified working, light bg, served via launch.json "open-ledger" port 8190). Uses CIRCUIT_TOOL binding vocabulary (carry/hold/route/flow/rest/gap/refusal).

**Topology A — marked 2026-06-21** (held-key ownership), implemented across all four files + demo re-verified. The commons is the record; ownership is a per-entry capability — the schema stores only `holder_proof = hash(secret)`, the poster keeps the secret. Authorship-as-**control** (retract this entry) split from authorship-as-**identity** (no needy-person column). Fresh secret per entry → every `holder_proof` unique → grouping profiles no one. "Your node" is computed client-side from the keyring you hold, never a server query — delivers the Circuit Tool's "you hold your own / no central authority / nothing to be kicked out of" for free while keeping incapacity #4 enforced in the schema, not the UI.
