Publication is not the threshold for Return. The library holding a pattern IS Return. Latent value is not a failure state.

**Why:** The falsifier for Return quality is Development-as-conduit (same class in, same class out), not non-publication. A pattern that completes, composts past individuation, and enters the library has genuinely returned — it holds latent value in the village container, available to seed when the right ground appears. The hau is preserved in the library, not only in circulating work.

**How to apply:** Do not use publication or seeding-now as the Return quality test. The correct test: did the Development phase transform the material (different class of thing, specific new capacities)? If yes, the pattern at rest in the library is Return. If no, the Development phase was a conduit regardless of whether anything was published. Latent dormancy ≠ Sealed Pile. The Sealed Pile is unlimited accumulation; latent dormancy is village container logic — retention tolerant of latent value, not function-indexed ejection.
