## The node, named

The escalation rule was already a router — one cheap classifier, seven conditions, two exits. This file only makes the shape explicit and checkable instead of felt each time.

```
            ┌─────────────────────────────┐
  drop ───▶ │  CLASSIFIER (cheap, local)  │
            │  seven conditions, OR'd     │
            └──────────┬──────────────────┘
                       │
         none trip     │     any trips
       ┌───────────────┴───────────────┐
       ▼                               ▼
   DAILY (conversational)     DEEP REVIEW (full-form terminal)
   local model, no metering   the only exit that escalates
```

## The routing table

| # | Condition (verbatim) | Exit if true | Standing |
|---|---|---|---|
| 1 | the movement creates public consequence | Deep Review | — |
| 2 | the movement asks another person for capacity | Deep Review | — |
| 3 | the body is strained or depleted | Deep Review | — |
| 4 | the desire feels urgent, proving, or identity-loaded | Deep Review | — |
| 5 | a hidden-cost smuggle is suspected | Deep Review | ✓ always named when it fires |
| 6 | the move creates commitment beyond today | Deep Review | — |
| 7 | the prior pass returned ambiguity | Deep Review | — |
| — | none of the seven | Daily | — |

**Matching law (from the authority file, unchanged):** lowercase substring match on the markers, whole-drop scope, deliberately narrow — better a check that misses quietly than one that fabricates a trip.

## The tiering identity

The router is where the terminal law and the compute budget turn out to be one law stated twice: the classifier and the Daily exit run on the cheap local model (`hermes3:8b` — live, no login, no metering); Deep Review is the only path that escalates to a frontier model. Cost discipline and escalation discipline are the same discipline.

## Jurisdiction

The router routes; it never marks. A trip sends the movement to Deep Review with its condition named — it does not decide the movement, deny the movement, or reduce what Kevin gets (the load-test guard and [[feedback_ai_never_self_limits]] both bind here). Condition 3 in particular is a routing fact about where review happens, never a directive to the body.
