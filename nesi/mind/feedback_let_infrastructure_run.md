Kevin, 2026-07-11: "let the infrastructure run... kevin has been running it by hand for too long."

**Why:** The organs are built — recognition organs, daily-cycle, dispatcher, metabolizer, membrane controller, governor trail. But Kevin has been the crank on all of them: invoking, sequencing, remembering, re-approving. The system's maturity is measured by how little hand-cranking it needs, and it is past the point where hand-cranking is care rather than cost.

**How to apply:** Prefer the built organ over asking Kevin to do the step. Use scheduled/automated paths that already carry his standing consent (dispatcher, daily-cycle, hooks) rather than routing every invocation back through him. His gates remain absolute — publish/delete boundary, membrane crossings, felt-reads ([[feedback_publish_delete_boundary]], [[feedback_body_read_is_his]]) — but everything below the gates should run without his hand on the crank. When a step exists as infrastructure, run the infrastructure; don't re-perform it manually or ask him to.
