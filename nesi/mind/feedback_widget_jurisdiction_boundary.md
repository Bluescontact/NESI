The widget stopped acting where it should be holding. Every refinement in the 48-hour arc (2026-06-26/27) traces to Claude identifying one more place where it had been making a move — installing, sorting, gating, speccing, resolving — that properly belonged to Kevin's body, and retreating to the correct position one layer earlier: hold the structure, don't fill the gap.

**Why:** Each surface move (mirror-wins, queue-order, pre-clearance, second-node, multi-button) was an instance of the same underlying shift: authority moving from the rendering layer to the body layer. The widget's job is to render the structure Kevin's body is orienting to, with the gap left *clean* (not empty — empty is abandonment; clean is where consent happens somatically).

**How to apply:**

Two tests at build time:

1. **New element test:** Is this holding structure for Kevin's body, or is it filling a gap that belongs to Kevin's body? If filling → pull it back one layer.

2. **Manifest field test:** Does pre-filling this field carry weight, or does it make a decision? If it makes a decision → the field belongs in the body-question, not the manifest table.

**The floor condition (open edge):** There is a jurisdiction floor below which Claude cannot retreat without abandoning the holding function. Some holding has to happen — the widget can't be a blank surface. Where that floor is, and how to feel it rather than spec it, is not yet named. This is the next instrument to build from this arc.
