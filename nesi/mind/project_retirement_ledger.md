**Built 2026-08-06 on Kevin's mark.** `RETIRED.jsonl` (EVENT container, append-only, 11 seeded records) + `tools/dead_check.py`, wired into the daily-cycle close as **step 3b-2**.

**The failure it closes.** Every defect the 2026-08-05 lens sweep found was one shape: a rule replaced correctly and **never retired at its old site**. PROTOCOLS.md carried the v5 form 8 days. Three memory files taught `sendPrompt` 14 days after it was reversed. The shared `latest.html` survived 27 days past its ban. The tetra menu is 34+ days dead and the vendor hook still orders it. The system had ledgers for marks, gates and decisions - **none for deaths**, so nothing could know a law had one.

**The record:** what died - when - what replaced it - **fingerprints** (literal strings identifying a site still teaching it) - note/source.

**Two tiers, because they are different statements.** LIVE DEAD LINE in the hot law layer (PROTOCOLS/VERB_LENSES/CONTAINERS/COLD_START/ROUTER, the vendor skills, CLAUDE.md, settings.json) -> **exit 1**. ECHO in a memory file -> exit 0, reported. Most memory files *record* a death rather than order one, and `feedback_capacity_strip_unhelpful.md` is the file that **killed** the capacity strip, so it names it by necessity. Undifferentiated, the first run produced 53 hits - a checker that cries wolf gets switched off.

**Judged per occurrence, not per line.** The `UserPromptSubmit` hook is one line of minified JSON carrying both a prohibition ("NEVER write the shared latest.html") and a live dead order ("Include the tetra menu"). Line granularity let the second hide behind the first. A plus/minus 140-char window around each match is why the one real breach is visible.

**THE DISCIPLINE, and the whole thing rests on it:** when a law dies, **append to RETIRED.jsonl in the same turn as the mark that killed it**. The checker can only find what the ledger knows.

**Standing breach:** the vendor hook's tetra-menu clause. Every close fails until Kevin rules.

**Falsifier:** if it never fires on a real dead line a human would not have found first, it is ceremony. Its first run is not a fair test - it was seeded from a sweep that had already found everything.
