# NESI — the 176 patterns against the vector equilibrium

**Status:** a siting proposal, not adopted. Companion to `NESI_VE_TWELVE_ORGANS.md`, same
method: the geometry describes existing structure, it never gates what's allowed to
exist, and no session fixes a felt-read on Kevin's behalf. Run on his ask, 2026-08-18:
*"every extraction, every pattern, every tool I've built is homeless... I want to route
everything into bucket on the VE."*

**What this is not.** Not a re-derivation of `patterns/` from scratch. Not a computed
clustering — every grouping below traces to something the patterns already say about
themselves, in a mark already made, on a date already recorded.

not 176 unrelated items.** On 2026-07-29 and 2026-07-30, Kevin ran a real-pressure
collapse of the (then) 157-pattern canon against `CANON_BUNDLE_part1-3`, and **ten
patterns survived it as organs** — each one carries this exact sentence in its own
`Lineage` field:

> *"one of ten organs surviving a real-pressure collapse of the 157-pattern canon, run

## THE PROPOSAL — ten organs, two open seats, one held-center candidate

The VE has 12 vertices, radially equal, plus one held center that is categorically not
a 13th vertex (`NESI_VE_TWELVE_ORGANS.md`'s own language, reused because the shape is
the same). Read straight off what's already declared:

- **10 of 12 vertices = the 10 organs**, as listed above. This is not a felt-read; it's
  a direct transcription of Kevin's own 2026-07-29/30 marks.
- **2 vertices open.** Candidates, not chosen: `the_silent_close` (the loose end above)
  and a second slot for whatever this pass's orphan sweep surfaces (next section) if
  any of it turns out to be hub-shaped rather than genuinely unsited.
- **The held center — a candidate, not a decision.** `witness_as_origin`'s own gist —
  *"the body is the origin of the witnessing coordinate system, not a sensor; origins
  are trusted-or-fail-closed, never witnessed"* — matches `membrane-controller`'s role
  in the twelve-organs file almost exactly: the one thing that does what none of the
  others do, deliberately non-participating in the same act it makes possible. But
  `witness_as_origin` is already absorbed inside `mark_it_at_the_body_or_it_does_not_cross`
  as one of that organ's two nucleation patterns — so naming it the held center would
  pull it back out of its own organ, a real structural choice, not a bookkeeping one.
  **This is exactly the kind of felt-read `NESI_VE_TWELVE_ORGANS.md` explicitly declined
  to supply on Kevin's behalf** — offered here on the same terms, not resolved.

**What is not proposed, on purpose:** which specific one of the twelve vertex
*positions* (not just "which ten things") each organ sits at, or which of the four
interchangeable body-diagonal axes carries the whole structure. Both are the kind of
fix `PROTOCOLS.md` says no session makes unilaterally.

## THE ACTUAL ORPHANS — what this pass found, honestly bounded

Six parallel reads covered all 176 patterns, each one read in full, extracting only
declared relations — never computed similarity. Three patterns turned up with **no
declared relation of any kind** (no `EXTENDS`, no cross-reference, no "cited by") **and
no appearance as a citation target inside any other pattern's own declared relations,**
across the full 176-file sweep:

- **`naming_the_invisible_brace.md`** — names an unassigned load-bearing role; its own
  file says it is NEW, with no Related section.
- **`survival_friction_capability_floor.md`** — chronic survival-layer friction
  preempting cognitive bandwidth; no declared relations anywhere in the file.
- **`the_locating_move.md`** — a system locates a person on true ground rather than
  steering; references a companion concept but not by any pattern's actual filename.

**The honest limit, stated rather than smoothed:** this is what turned up in one
full read-through, not a grep-verified zero-citation count. `THE_BEDROCK`'s own
standard for a claim like this is a direct check against disk — `grep -rl` for each of
these three names across all 176 files — which this pass did not run. **Treat these
three as the strongest orphan candidates, not a certified final list**, until that grep
is run.

**These three, and only these three (pending that grep), are what "homeless" actually
names once the organs are accounted for.** Everything else in the 176 already declares
where it stands relative to something else — it was unsited on the VE, not unsited,
period.

## WHAT THIS DOES NOT DO

It does not assign an organ to a specific vertex position. It does not pick the held
center. It does not decide whether `the_silent_close` is a genuine eleventh hub or
already-absorbed-under-another-name. It does not run the citation grep that would turn
the three orphan candidates into a certified count. It does not touch any pattern file,
any organ, or `bench.json`. Same falsifier as `NESI_VE_TWELVE_ORGANS.md`: **if a future
edit to a pattern or an organ needs this VE placement to make sense of it, the geometry
has become load-bearing on the wrong side.**
