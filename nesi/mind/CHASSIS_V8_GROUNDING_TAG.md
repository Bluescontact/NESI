# Chassis v8 — grounding tag (candidate, 2026-07-25)

**Status:** candidate, not canonical. v5 remains operative per PROTOCOLS.md; v6, v7, v8 all sit un-adopted until a separate mark promotes one. Files: `nesi/mind/_chassis_v8.html`, mirrored at `_widgets/_chassis_v8.html`.

## Where this came from

Directly from a substrate pattern produced earlier the same session: **"Symmetrical Blindness From Asymmetrical Visibility"** (PROMOTE-READY, `_INTAKE/SUBSTRATE_BRIEF_Cost visibility and reciprocity as independent axes.md`). The pattern's claim: two parties each carry a real cost vivid to themselves and invisible to the other, so both honestly conclude they're the net carrier — driven by visibility, not dishonesty or magnitude. The fix isn't adjudicating who's right; it's ending the asymmetry.

v7 built Kevin's half: the capacity strip, where he names his own bandwidth before anything is surfaced, never inferred by the AI. That left the other half of the pattern unaddressed — nothing told Kevin how solid the AI's own claim was on a given card. Without that, he's in the same blind spot: forced to trust every card equally or discount all of them, since the AI's confidence never crossed into view.

## The one addition

A **grounding tag** on every card, alongside the existing light/heavy weight tag:
- **grounded** — traces to something checked (a file read, a computed value, a floor-indicator run, a verified quote).
- **reached** — the AI's synthesis, judgment, or interpretation. Real, but not independently verifiable the same way.

Binary and qualitative by design, not a confidence percentage — the same substrate run composted a candidate ("Naming Collapses Into Pricing") for exactly this failure mode: once a cost/confidence is stated in comparable units, it becomes rankable, and ranking is a market. The grounding tag stays in its own two-value vocabulary, never a number.

## What was deliberately left as v7

Locator, capacity strip, read/decide zones, back-anchor, collapse-all, the body-directing hard rule — all unchanged. v8 is one addition, not a rewrite, matching the same additive discipline as v6→v7.

## Crossing to canonical

A separate mark, same as v6 and v7.

## Falsifier

If a future card's grounded/reached tag doesn't change how much scrutiny Kevin gives it before marking — if he treats both the same either way — the tag is decoration, not the symmetry fix it's meant to be.
