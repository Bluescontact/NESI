## G1 · Owner on every decision
Every rendered decision carries an owner line — Kevin / a named person / an authority / **unowned (flagged)**. "Route to the real owner" is a standard pre-authored exit beside hold/drop/go. Source: Kevin's own extracted meta-law — "When a decision drifts toward me, I name it once and route it to its real owner. I don't pick up what isn't mine to hold." An ownerless decision is the stall condition (the trailer); rendering it flagged is the preemption.

## G2 · Exits carry their named return
Every exit states what force returns when taken ("returns → attention freed — no thread to chase"). Choosing a move is choosing a named force-return, not an abstract state. This is data about the MOVE — never a gauge of Kevin (see composted-out list).

## G3 · The convergence gate
Before rendering a field of forks, run one check: **do all routes pass through the same node?** If yes, that node renders first as THE decision — "the move is not one of the options; it is the precondition of all of them" — with the forks visibly downstream, marked later, never hidden. A convergence read is an interpretation: tag it `reached` unless verified, and Kevin can strike it.

## G4 · The bounded ask
Every gate/manifest asks exactly ONE answerable question. "Not yet" is a pre-authored, legitimate answer on every ask; "later" is a visible parking state, never a silent drop. Rationale: "a bounded ask is answerable by a tired person; an unbounded one is not" — the upstream boundary on decision-fatigue gravity.

## G5 · Commit-to-field
An acted/settled decision migrates OFF the working surface and onto the terrain/field as a settled dot (still clickable — acted is a state, not a wall). The working surface holds only live decisions; the field accretes. The surface can never silt up with finished work.
