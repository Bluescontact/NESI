**Kevin's opening, this session:** *"the library was built off of aoc.. and now we are
mapping the relationships to everything that emerged, and discovering how thing map and
relate and hold each other."*

`public_site/library.html`'s "Gifts" section is already this mapping, one layer deep —
its 24 cards are organized by AOC's six edges (Relationship, Self-Knowledge, Gift,
Consent, Circulation, Deployment) across the four vertices (Differentiation,
Connection, Boundaries, Architecture). This file extends that same placement to
everything built downstream of the manuscript since — read by two independent lenses
(buckminster-fuller, stuart-cowan), each reading the geometry and the live artifacts
directly rather than a summary of them.

## The governing line

AOC's own self-diagnostic (Ch28, unchanged through the v2 rebuild) named Circulation
and Deployment — both touching the Architecture vertex — as the weakest axes, and gave
the reason: *"Architecture is moved by deployed loops closing in substrates the makers
did not build — not by more-accurate text."* `aoc-v2/90_weave/DELTA_FROM_V1.md`'s
forward instruction, after a full ten-agent rebuild pass confirmed the gap had
**widened** in relative terms, was one sentence: **close one loop.**

Everything below is read against that line.

## Where the geometry is structure now, not description

**Deployment (Boundaries↔Architecture) — done, not written.**
`nesi/mind/LEARNED.md` law 22 (a gate is a filesystem fact, not an exhortation — a
file, a hash, a row only a hand can write) is enacted directly in `nesi/game2d/`'s
`check_all.js`, `gate/LEDGER.jsonl`, and `MARKS_LOG.jsonl`. This is architecture
instantiated as a boundary the machine cannot talk past — a substrate built years after
the manuscript, closing a real loop AOC could only describe.

**Circulation (Connection↔Architecture) — outbound leg built, return leg unverified.**
`tools/transmission_engine/` fabricates the outbound half in the filesystem: real SVG
artifacts (`dist/*.svg`, `MANIFEST.json`, `CLUSTER_MAP.md`) that leave the corpus and
travel without Kevin attached. `osg-v6/the-engine.html` names itself as the bridge
between the Machine (internal) and the Field (external released commons). Both lenses
independently flagged the same gap: neither found evidence, in what they read, that
anything has actually returned through that bridge yet. It is positioned to be the
trim tab DELTA calls for — *positioned is not verified* (Cowan's phrase).

**Self-Knowledge (Differentiation↔Boundaries) — the strongest closed loop found.**
LEARNED.md's own shape — incident → sourced law → boot-read persistence → inline
`[re-broken]` tags where a law's loop failed to hold (laws 5, 28) — is, per the Cowan
reading, the single strongest circulation in the corpus: it states its own falsifier
and shows its own failures inline rather than smoothing them.

**Relationship (Differentiation↔Connection) — genuinely differentiated readers.**
`counsel/`'s six lens subfolders (composite, cowan, fuller, gamecraft, kevinlens, nesi)
running CUT/DREAM/GROUND/SHAPE/RECONCILE_AND_DREAM in sequence — each lens reading and
modifying what the prior lens deposited — is a real layer on this edge: distinct
standpoints, genuinely load-bearing on a shared artifact.

## The shape of osg-v6 itself

Read directly, not assumed: the site's own hero grid labels four pages "Face 1"
through "Face 4" — the Light, the Door, the Machine, the Field — matching the
tetrahedron's vertex count, not six. `the-engine.html` is reached only through nav,
never a face card, and its own lede is the language of an edge (what connects Machine
and Field), not a fifth vertex. The site did not decorate the vertex count with a sixth
face — it built the weakest edge legible enough to earn its own page. That is itself a
Fuller-shaped move: make the missing axis visible by building it, not by describing it.

## Trim tabs found (where one piece lets another do less)

- **The Engine** lets `the-machine.html` and `the-field.html` each skip re-explaining
  the loop between them — one page carries the joining work once.
- **LEARNED.md** lets every check in `check_all.js` skip re-arguing its own authority
  each run — the law is the tension member, not the code.

## Forks held open (not resolved here — Kevin's to close or leave open)

1. **Is `the-field.html`'s "what returns strengthens canon" an operating loop, or an
   aspiration stated in the present tense?** No visible return-ledger was found by
   either lens. This is the one place in the material that could take a downstream
   user's contribution into "canon" without a visible mechanism showing the fold
   happened — the floor check both lenses ran independently.
2. **Did the 2026-08-22 positive-framing resynthesis pass on osg-v6 ever cross from
   lint into smoothing a real unclosed gap** (rather than collapsing genuinely
   redundant negative clauses)? Unverified which happened, page by page.
3. **Does the aoc-v2 rebuild count as closing a loop, or is it more accurate
   map-making that the manuscript's own bottom line says doesn't cross the
   territory?** DELTA's own line: *"a sharper map of the chasm is not a bridge."*

None of these are problems flagged for repair — per law 27, a repeated dead end here is
navigation data naming where an upstream deposit is missing, not a verdict on the work.

## Bearing on "the white paper"

Two documents currently answer to that name in this corpus, and this mapping suggests
they're not competitors but different edges:

- **`aoc-v2/90_weave/MANUSCRIPT.md`** carries Architecture — the geometry itself,
  self-audited, honest about its own weakest axes.
- **`nesi/mind/WHITE_PAPER_LOAD_BEARING_PATTERNS_2026-08-24.md`** carries something
  closer to Deployment — 23 patterns admitted only because each is cited by name
  inside code or a governing document actually running today, i.e. filtered by the
  same "fixed by use not text" bar AOC set for itself.

If the site's library is to keep growing along AOC's own geometry rather than beside
it, the natural next placement is not choosing one white paper over the other but
citing both at the edge each actually occupies — and building the one piece of visible
return-mechanism (fork 1, above) that would let Circulation stop being the axis every
reading keeps finding weak.
