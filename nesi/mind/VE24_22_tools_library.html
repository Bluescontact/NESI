The one thing genuinely shared

verbatim Both files carry the identical 29-pattern negative-word regex array (corrected on verify — first counted as 27; an independent re-count via grep -o "/gi" found 29 in both files, byte-identical) (does not, cannot, never, nothing, fails?, stale, defect, and so on). framing_check_skills.js's own comment names this explicitly, immediately above the list: "Same word list as nesi/game2d/tools/framing_check.js. Keep the two in sync by hand if either changes — duplicated deliberately rather than shared across a game2d/tools boundary and a project-root/tools boundary that otherwise have no dependency on each other."

Verdict: this is a deliberate, declared duplication of one constant (the word list) between two structurally independent instruments with different targets, different pass conditions, and different units of measurement. It is not drift — drift would mean the two diverged from a once-shared origin without anyone noticing. Here the divergence is the design, stated in both files' own headers, and the one shared piece is named as shared on purpose rather than accidentally copied.
