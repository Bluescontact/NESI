## Transferable Form

An organ does not build itself — it requires a regulated substrate. The canon's autonomy depends on the builder constructing the circulatory system (conditions, input gates, constraint architecture) that allows it to receive and operate. "Self-operating" does not mean "self-sustaining without infrastructure."

The builder's work is not managing the organ. It is building the vascular system the organ requires. These are distinct obligations. The organ metaphor obscures this if taken too literally: calling something "self-operating" names autonomy of function, not independence from substrate.

---

## Mechanism

Every self-operating system requires active construction of substrate before autonomous operation begins:
- Immune system → bone marrow + thymus
- Forest → mycorrhizal network + soil biome
- Fire → fuel + oxygen + ignition

The "self" in self-operating names autonomy of function, not independence from substrate. The system that appears to run itself is running on infrastructure someone built and someone tends.

The paradox: the void the organ operates in is not empty — it is actively maintained. The tending is invisible precisely when it is working.

---

## Falsifier

If self-operating systems genuinely require no substrate construction, the pattern is false.

**Verdict: does not land.** No known self-operating system meets the falsifier condition. The substrate requirement is universal across biological, ecological, and engineered systems. The canon is not metabolizing its own deployment infrastructure — the builder is.
