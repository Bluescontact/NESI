## Transferable Form

When everything a system attempts degrades by roughly the same margin at once — every effort, every plan, every attempt underperforming with no single identifiable fault — the problem is not in any of the attempts; it is upstream, at the zero-point they all measure against. Before offering a struggling system more things to do, establish what it stands on: load-side prescriptions given to an unreferenced system are billed against capacity it does not have. And the costliest reference is not the missing one but the flickering one — the system spends itself re-checking the ground instead of extending from it.

## Development

**Ground is a relation, not a part.** The reference is not a component wired into the system — it is the zero-point every other element measures against. Loads do not connect to ground; they compare to it. This is why its failure is multiplicative rather than additive: one unreliable zero forces N simultaneous re-measurements against a moving point, so the cost scales with the number of things referencing the ground, not with the size of the fault.

**The failure signature is distributed shimmer.** A broken load fails locally and loudly; a bad ground fails everywhere and quietly — every circuit picks up the same injected noise. On the human side: everything degrading a little at once, nothing identifiably broken. Ground is never measured directly; it is diagnosed by the distribution of error across the loads. This yields the common-mode diagnostic: uniformity of deficit. When every load-side effort underperforms by roughly the same margin, the fault is upstream at the reference — this converts the pattern from a sequencing rule into a fault-location instrument.

**Intermittent ground costs most.** A reference that is sometimes there trains the system to spend continuous capacity verifying it. The signature of unreliable ground is not collapse but oscillation: checking behavior, re-verification, attention returning to the reference instead of extending from it. Broken load fails at the task; unreliable ground fails between tasks, in the checking. Absent ground can cost less than flickering ground, which is why clean loss sometimes stabilizes a system faster than a reference that almost holds. This drain differs in kind from a corrupted reference — a corrupt origin misleads (confident wrong readings, epistemic and per-measurement damage); an unreliable ground conducts — a circulating drain paid by every referencing circuit whether or not any reading is taken. Energetic, continuous, uniform across all loads.

**What grounding buys is comparability, not motivation.** A fixed zero makes magnitudes comparable — the reference converts an incomparable set of options into an ordered one. Without a shared zero, priorities are not hard to rank; they are formally unrankable. Self-organization is priority collapse falling out of comparability, not a surge of will.

**Only load reveals ground.** In practice, ground integrity is tested by injecting current — a ground's state cannot be read without putting a small load across it. The operative distinction is not load versus no-load but production load versus calibration load — one small, revocable application sent to read what the body does when it lands, run for the reading, not the result.

## The two registers this adds (per the shaping instruction)

1. **Helper-side triage rule.** The pattern's native register is second-person triage. Where existing origin patterns are first-person (where I measure from) or system-internal (what paths I pre-load), this one governs what one system offers another in collapse — advice, aid, policy, onboarding. Its failure mode — adding load rather than establishing ground — is a diagnostic of the helper, not the sufferer. First question: "where are you standing," before "what will you do." Every load-side prescription offered to an ungrounded system is billed against capacity the receiver does not have.
2. **Flickering-reference drain.** A load-register claim canon otherwise holds only epistemically (via [[translated_origin_failure_mode]]): an intermittent ground costs more than no ground, because the system spends continuous capacity re-verifying a moving zero instead of extending from a fixed one. This is stated for support (energetic, continuous, uniform across all loads), not for epistemics.

**Explicit hand-backs:** capture-vs-genuine-ground cases route to [[translated_origin_failure_mode]]'s existing machinery; the reference-as-zero vocabulary and the temporal-face question stay filed under [[witness_as_origin]], not re-derived here.

## Failure modes (shrinking the pattern's own jurisdiction)

1. **Grounding as permanent deferral.** The pattern's most dangerous false positive is the person who is not ungrounded but load-avoidant — "I must establish ground first" as an infinitely extensible license to never wire a load. Without a named terminus where ground is declared good-enough and load becomes mandatory, "ground first" fails identically to "set goals" — a ritual substituting for the thing it promises.
2. **Ground built under load.** Whole substrate classes violate the ordering — balance is learned by walking, income becomes ground by being earned, trust becomes reference by being risked. In bootstrap systems, reference and load co-arise; applying "reference before load" there prescribes paralysis. The pattern's true jurisdiction is only systems where a reference can pre-exist its load, and the jurisdiction test must be run per instance.
3. **Stable capture reads as ground.** The pattern detects ground presence, not ground quality. A cult, an addiction, an abusive relationship all supply a rock-solid reference — felt safety, answerable priorities, visible self-organization. Every signature the pattern names as "grounded" is emitted equally by a system locked to a captured reference. Self-organization after grounding is evidence of any ground, not good ground.

## Open edges

- Identity question, unresolved: this may not be a new object but the temporal face of [[witness_as_origin]] — a sequencing law (origin as prerequisite) rather than a geometry (origin as unoriginated point).
- The terminus is unnamed: the pattern has no criterion for declaring ground good-enough, so it cannot yet defend itself against its own weaponization as permanent deferral.
- The second instrument is missing: the pattern reads whether a system has settled, not what its reference is tied to. Distinguishing free ground from captured ground requires an instrument this pattern does not contain.
- The jurisdiction test is unbuilt: pre-referenceable versus bootstrap must be decided per instance.
- The calibration-load protocol is unspecified: how small, how revocable, how the reading is taken and by whom.
