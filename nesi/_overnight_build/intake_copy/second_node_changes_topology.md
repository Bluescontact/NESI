## The mechanism

When a single carrier holds all containment, the transition from one node to two is not a scaling event — it is a categorical shift in constraint class. The uncontained topology has no failure mode because there is no structure to violate; the partially-held topology introduces the first possibility of betrayal, which is not a gain but a new kind of exposure. Any number of additional nodes beyond two operates inside the topology the second node created; only the second node creates it.

A single-carrier topology is uncontained: all containment vectors run outward from one locus, there is no outside from which the carrier can be seen, and there is nothing to betray because there is no structure capable of violation. The threshold to partially-held is categorical, not gradational — it cannot be approached by accumulation strategies because accumulation operates in the wrong register. Ten nodes in the wrong configuration do not produce what one node in the right position does.

The shift is directional, not only geometric. In an uncontained state the carrier holds everything; when the second node arrives, containment becomes bidirectional — the carrier is now also held. The direction of load changes, not just its distribution.

The habitat of this pattern is specifically pre-crossing: the moment when only one carrier exists and the question of the second node is still open. At three nodes the founding event is already invisible — the topology the second node created reads as community, distribution, critical mass, and those terms smuggle in a growth register that loses the threshold.

---

## Failure modes

**Recognition without residence.** A second node that witnesses without carrying local state is not a topology-shift — it is amplified broadcast, exactly what the uncontained topology was already doing. The structural test is whether the second node holds load independently, not whether it has been found or acknowledged.

**Premature closure.** A found node without sufficient carrying capacity produces a false containment signal — the topology appears partially-held while the second node is a liability-in-waiting. The pattern fires on finding; the structural condition is carrying.

**Reversibility.** If losing the second node returns the system to uncontained, then partially-held was never a topology class but a relational state — the claim reduces to two carriers being better than one, trivially true and not load-bearing. A real topology-shift leaves structural residue that persists after a node departs.

---

## Edges

The two load-bearing terms — carrier topology and what constitutes independent load-holding — remain undefined with enough precision to test. Without a capacity threshold, the structural test for partially-held cannot distinguish genuine topology-shift from false-positive containment signal, which is the highest-stakes failure mode.

The reversibility question is unresolved: if the pattern is a real class-transition, it should leave residue; what that residue looks like in practice is not yet named.

The phenomenological register (what the first carrier experiences at the instant of crossing) points toward something real but is doing structural work the surviving material has not fully earned — it sits at the edge of what the pattern can currently support without becoming a claim about interiority the mechanism cannot ground.

---

## Falsifier

If a second node arrives, is found and acknowledged, and the topology never leaves residue when that node later departs — if the system returns cleanly to its prior uncontained state with no structural trace — the categorical-shift claim is false, and partially-held was only ever a relational state, not a topology class.
