## Transferable form

When a system has only one committed node, all forward costs route to that node by default — not because the carrier chose to absorb them, but because the container architecture has no other valid landing points. A village container changes the surface area over which cost distributes; it does not reduce the total cost. The carrier singularity is a design diagnosis, not a character judgment.

## Mechanism

The independent variable is container topology. A single-body topology is not a degenerate case — it is the default when no village container has been built. The system selects its most committed node as the cost sink because that node made the most forward deposits and is therefore the only valid destination the routing table recognizes.

Carrier role is produced by architecture, not chosen by personality. The exit condition is container change, not carrier change. Behavioral modification at the carrier level (rest more, delegate more, give less) operates below the ceiling — the ceiling is structural, set before any ask or delegation is possible.

Presence of bodies does not equal presence of distribution wiring. A village container can exist by membership test while still routing all cost to the carrier, if cost-sharing was never built into the container's operating logic. This is the pattern's most dangerous false positive.

The bidirectional lock is the pattern's hardest edge. If carrier concentration drains the capacity needed to build village infrastructure, and absent village produces carrier concentration, the system can lock itself into single-body topology through mechanics alone — no one's choice required. The unlock condition under this loop cannot be internal; it requires a node that enters laterally, not recruited through the carrier's own forward deposits.

The carrier's cost-bearing may function as the container's gravity — the attractor that makes the village legible to its members. If so, distributing cost away from the carrier does not relieve the system; it dissolves it. Cost-distribution and container-integrity are in direct tension at this edge, and the intervention logic inverts entirely.

The pattern sits prior to delegation, prior to policy, prior to any social fix. Its diagnostic moment is body-recognition — exhaustion, resource drain, the felt sense that forward motion costs more than it should — before any organizational or relational diagnosis is attempted.

## The distribution mechanism (closing the gap)

The sibling pattern in the same source session — [[second_node_changes_topology]] (already canon) — supplies the actual distribution mechanism this pattern names but does not build: containment becomes bidirectional the moment a second node holds load independently, not merely witnesses. Operationalized test: pull each node out one at a time — if only one node's absence collapses the container, topology is still single-body regardless of headcount; the container distributes cost only once at least one other node's departure would also break something.

## Failure modes

- **Membership without wiring.** Bodies present, distribution logic absent — the false positive named above.
- **The bidirectional lock.** Carrier concentration and absent village co-produce each other with no internal exit.
- **Distribution vs. integrity tension.** If carrier cost is the container's gravity, removing it may dissolve rather than relieve the system.

## Open edges

- The boundary between this pattern and village_container_vs_system_container's retention-logic axis has not been drawn — this may be a named consequence rather than a separate mechanism.
- The bidirectional lock, if real, requires a theory of lateral entry that the source material does not address.
