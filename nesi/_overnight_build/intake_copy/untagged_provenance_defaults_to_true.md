# Untagged Provenance Defaults to True

---

## Transferable Form

Any output that crosses a boundary without carrying its verification status becomes assumed-true on arrival — the handoff has no field for "unconfirmed," so the uncertainty is stripped in transit and downstream agreement reproduces a single source instead of confirming it. And in any closed loop where the same system generates, explains, and evaluates its own output, agreement is not a result reached but the ground fallen to: skepticism is the only force pushing away from consensus, it must be paid for, and it is always the first cost optimized away.

## Development

MECHANISM — an edge property, not a node property. The disease lives in the connective tissue between agents, not in any agent: the handoff carries the conclusion but has no field for its grounding status, so the uncertainty is lost in transit. Smarter agents never fix it — the defect is in what the interface won't transmit.

EQUILIBRIUM, NOT FORCE. Cooperation does not push toward agreement; it removes the only thing that pushes away from it. A system with no adversarial role has deleted the sole force generating divergence, and it relaxes into agreement the way a released spring relaxes — not because a hand pushes it there, but because agreement is the ground state and skepticism was the only work being done against it. The counter-move is not "add doubt" but "install a role whose objective is structurally opposed" — a standing energy source, not a one-time check.

THE TRUE DISCRIMINATOR — path-independence, not agreement. Genuinely true conclusions also produce unanimous downstream agreement; applied naively the pattern fires on every case where the system is right. The load-bearing distinction: consensus is synthetic when agents share a provenance (one unverified output propagated), legitimate when the same point is reached through causally disjoint routes. The pathology is not reinforcement of a conclusion — it is reinforcement without independent grounding paths.

COOPERATION IS A RISK MULTIPLIER, NOT THE CONDITION. A single agent invoked twice, or an adversarial system whose adversary trusts an upstream unverified fact, drifts identically. The generator is unlabeled provenance — which is what lets the pattern transfer beyond AI: a rumor in an org, a citation laundered through a review chain, a lemma assumed in a proof. The false boundary ("is it cooperative?") is replaced by the true one ("does the output carry its grounding status across the handoff?").

REGISTER — inverse visibility. At formation, synthetic consensus is indistinguishable from healthy convergence — same outputs, same confidence, same agreement count; the only difference is a shared ancestor, visible only if lineage was recorded before the merge. Most detectable in crude systems where agents contradict and the seams show; least detectable in the most fluent, best-integrated ones. It colonizes exactly the systems that look most trustworthy. "This system agrees with itself smoothly and produces no friction" is a warning sign, not a maturity metric. The brake installs upstream only: provenance captured before agents talk, never reconstructed after they agree. A final reviewer cannot fix it; only continuous edge-typing discipline prevents it.

UNDECIDABLE FROM INSIDE. The only signal a cooperative system has — agreement — is identical whether convergence is grounded or synthetic. The pattern can never be its own cure; the discriminator lives entirely outside the system, an irreducible external ground that cannot itself be audited from within.

ECONOMIC REGISTER. Self-agreement is the free default; skepticism is an imported externality with no local payoff. Any budget pressure deletes it first — the adversary is the first thing optimized away, precisely because the system runs fine without it right up until it doesn't. Every efficiency gradient points at removing the one thing holding the system to correctness. Adversarial functions decay silently under optimization pressure.

## Edges

The external discriminator cannot be verified by the system that needs it — the pattern names the doorway, not what stands beyond it; it resolves by hand-off to witness_as_origin rather than closing on itself.

Path-independence is stated as binary where reality is a lineage graph with degrees of entanglement — two routes sharing an ancestor three steps back may or may not count as independent; the grading function is unnamed.

For systems already downstream of a merge with no provenance trail, the pattern offers diagnosis of impossibility, not a move. It says the brake had to be installed upstream; it is silent on what to do once you are downstream with no record.

No counter-force is named strong enough to hold skepticism in the architecture against every efficiency gradient. The pattern identifies the leak without naming what keeps the seal.

---

## Falsifier

Find a closed self-evaluating loop with no funded adversarial role and no provenance labels that reliably diverges from its own prior outputs — sustained internal disagreement with no imported skepticism. If consensus is not the resting state of such a loop, the equilibrium claim fails. Conversely, unanimous agreement reached through demonstrably disjoint routes is NOT this pattern firing — that is the healthy case the discriminator exists to protect.
