## Transferable form

When the same failure appears across every instance of a relationship — every delegate, every collaborator, every recipient — the pattern may be a property of how the observer is looking rather than a property of what is being observed. The check is structural: a field-pattern is only earned where the boundary was definable before the failure and the other party declined to observe a defined boundary. Without that condition, the failure belongs to the lens.

## Mechanism

The mechanism runs on a falsification condition. Claim: "everyone I delegate to fails." For this to be a field-pattern (a property of the people), you need at least one case where the boundary was explicit, operationally clear, and declined — not unclear, not implicit, not communicated after the failure, not assumed from context. If no such case exists, the claim cannot be distinguished from: "I observe failure everywhere I look," which is a lens property.

The critical distinction is between **underdefined** and **declined**. A boundary that was never operationalized cannot be violated — it can only fail to be guessed. The failure to guess is not the same failure as the failure to comply. Conflating these is where the lens does the work the people are being blamed for.

**The register audit function:** scan the full set of instances. Ask of each — was the boundary statable before the fact? Was it stated? If neither answer is yes in any instance, the pattern has no field-evidence. The audit does not require all instances to pass — only that at least one does. Without one clean instance, the universal claim ("everyone," "always") is unearned.

The structural truth: when a pattern is universal across a delegator's field, the most parsimonious explanation is the delegator, not the field. This is not a moral claim. It is a base-rate claim. The burden of evidence shifts — you need positive evidence of field-pattern, not just accumulation of instances.

**The named exit from the trap:** the pattern is only earned where the boundary was definable (the relationship admitted of specificity) and the delegator declined to define it. This is the falsification bar. Pass it and the field-claim holds. Fail it and the lens-claim is more parsimonious.

## Failure modes (of the check itself)

1. The delegator defines the boundary post-hoc after observing the failure, then treats the retroactive definition as the pre-existing standard — a false pass.
2. The boundary was "obvious" or "implied" — this is not a defined boundary; obviousness is lens-relative.
3. The delegator defines the boundary but buries it in ambient communication such that operationalization was not possible — partial credit at best, not a clean instance.
4. The audit is run in bad faith to find one minimally qualifying case and stop — the check requires that the qualifying case represents the relationship's normal operating terms, not an exception constructed to rescue the claim.

## Falsifier

At least one instance in the full set where the boundary was statable before the fact AND was stated AND was still declined by the other party. If no such instance exists across the full set of delegations, the "everyone fails" claim is falsified as a field-claim and must be re-read as a lens-claim.

## Edges

The check assumes the delegator can accurately remember whether boundaries were stated — but memory of self-generated communication is systematically inflated. The audit may need an external record to be trusted, which reintroduces a dependency on documentation the delegator also controls.

The pattern does not yet have a clean account of mixed cases: where some instances are genuine field-failures (boundary stated and declined) and others are lens-failures (boundary absent). The more honest result in mixed cases is partial — "some of this is field, some is lens, here is where each lives." The resolution condition for mixed cases is unresolved.

The deeper tension: once a delegator has run the audit and identified the lens as the driver, the practical move is unclear. Defining boundaries more precisely is necessary but not sufficient — there may be a preference or expectation structure that reasserts the same frame even when boundaries are operationalized. The check identifies the location of the problem; it does not yet contain an account of how the lens is retrained or dissolved.
