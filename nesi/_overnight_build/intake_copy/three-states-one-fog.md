# Three States Wearing One Fog

*slug: `three-states-one-fog`*
*Promoted: 2026-07-21 · Source: The Membrane — human-gate pattern family, repair pass same day*
*EXTENDS `source_check_before_giving.md` · originally drafted as three states; state 3 deduped and dropped during repair*

---

## Transferable Form

"Not settled yet," read on a held-but-not-yet-crossed object in its dead-time interval, can cover two structurally distinct source-states: material genuinely still cooking, and material ready but not re-approached (avoidance wearing the costume of standards). The two are phenomenologically identical — one felt channel asked to report on both collapses them by construction. The discriminator cannot live in feeling; it lives only in the time-stamped approach-history of the object.

---

## Development

**Honest collapse, not forced novelty.** The originally-proposed third state — a loop returning "almost" with no nameable gap — carried no mechanism of its own. Its entire signature was already owned twice in canon: it is `dread_of_sufficiency.md`'s second diagnostic and `translated_origin_failure_mode.md`'s detection test. The proposed distinct habitat (the dead-time interval of a held object) was a new location for an already-canonized mechanism, not a new mechanism. State 3 is dropped as its own category and cross-linked instead: when the two-state sort returns "almost, no gap," that reading is `dread_of_sufficiency.md` or `translated_origin_failure_mode.md` surfacing — referenced, not re-invented.

The genuine delta: a clean two-state extension of `source_check_before_giving.md`, which explicitly left its states unnamed and lives at the output moment of giving. This pattern moves upstream into the holding interval before the cross, and names two states with a per-state trace-discriminator.

The actuator, built on an approach-history ledger:
1. **Completion gate** — has this object already crossed the membrane once? If yes, exclude from the fog-sort entirely. Settled work cannot be recruited back into the loop it diagnoses.
2. **Trace pull** — no prior approach-history defaults to State 1 / WAIT, logged with a timestamp.
3. **Count + gap test** — approached-and-set-down 3+ times (borrowing `dread_of_sufficiency.md`'s threshold): gap namable → State 1, WAIT, log the named gap for next-approach verification. Gap un-namable → force a time-boxed re-approach whose only permitted outcomes are cross or name a concrete gap.
4. **Break externally** — if the forced re-approach also returns "almost, no gap," the mechanism is `dread_of_sufficiency.md`/`translated_origin_failure_mode.md`, and release requires a structurally-independent second origin, never another self-run approach.

Meta-stop: one sort pass per object per session; a same-session re-run is itself logged as a state-2 approach feeding the count, not a fresh diagnosis — self-enforcing via the same ledger.

## Edges

The two named states are grounded in a discriminable observable (approach-history), not fabricated the way the original three-state taxonomy's cut third leg was — but the naming is still an addition to `source_check_before_giving.md`, not a recovery from it.

**Named risk, carried forward at crossing, not resolved:** the external-break release (step 4) inherits `translated_origin_failure_mode.md`'s own open problem — a recruited second origin must be genuinely independent, not merely a second person inside the same frame. No test yet distinguishes the two. See `membrane/WATCHERS.md`.
