## The mechanism

When someone says "well, I assumed…", the response is binary: write the assumption into the shared agreement, or let it go. The move outlaws the third state — carrying an unwritten expectation as silent grievance — by converting every surfaced assumption into either shared text or discharged energy. It fires on a spoken marker in live conversation, requiring no instrument, document, or session.

One verified sentence carries the whole pattern: on the verbal marker "well, I assumed…", exactly two branches — write it in, or release it. The moving part is the exclusion of the middle. Silent grievance is made formally illegal; a felt expectation must resolve into shared text or discharge.

Detection is retroactive. The test has no scanning phase. Assumptions are detected only when they surface verbally — which means detection is outsourced to conflict itself. This is a discharge valve, not a filter: it runs at the point of friction, never before. Silence never triggers it. Undetected assumptions accumulate exactly as long as the relationship stays smooth. The detector IS the leak, and any honest deployment of the pattern must own that.

Neighboring patterns (invisible brace, undeclared disjunction, unshown cost) operate at the document or ledger layer. This one lives in live speech — the exact moment the marker leaves someone's mouth. It is a conversational reflex, not an audit procedure: a speech-triggered micro-protocol, the first of its class in the library.

---

## Failure modes

**The third state may only be renamed.** The causal claim rests entirely on whether "carry it and resent it" is actually blocked or merely relabeled. A party can say "okay, let it go" while continuing to carry. That failure is invisible from inside the mechanism: the test discharges only what gets voiced, converting honest parties while leaving strategic ones untouched. Without a downstream audit, the pattern is a filter on personality, not a structural guarantee.

**The release branch has no ledger.** Unrecorded letting-go leaves no evidence the debt was cleared rather than driven underground. Worse, felt, non-specifiable expectations cannot take the write-in branch at all — they cannot be reduced to a clause — so the binary silently routes exactly the relational material that matters most through "let it go."

**The write-in branch is an attack surface.** "Well, I assumed…" can be performed strategically to renegotiate terms after the fact: the test launders a demand as a surfaced assumption, and write-in becomes a unilateral amendment path. The test holds only if writing-in requires the same bilateral gate as the original agreement.

**No rate limit.** Nothing caps write-in frequency. A relationship running the test repeatedly accretes a contract that thickens forever — every surfaced assumption becomes a clause — until the written layer replaces the relational layer it was meant to protect. Failure signature: a document that grows while trust shrinks.

If clause-count rises faster than assumption-recurrence falls — if a relationship running this test repeatedly accretes written terms without the same surfaced assumption ever ceasing to resurface — the test has become a legalization engine rather than a discharge mechanism, and should trip a brake.
