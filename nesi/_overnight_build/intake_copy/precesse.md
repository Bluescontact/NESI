# Precesse

## Transferable Form

Result arrives orthogonal to intended action. The geometric mechanism of the Return vertex in a non-transactional economy: the consequence that was not aimed at, produced as the unavoidable structural outcome of the action's geometry.

---

## Development

The bee intends to gather nectar. Pollination is not the bee's goal — it is the orthogonal consequence of the geometry of the action. The bee cannot gather nectar without pollinating; pollination cannot fail to occur if the bee acts. The return is not incidental. It is structurally guaranteed by the action's form.

This names what "non-transactional return" describes but does not explain. Non-transactional return names the outcome type: what arrives is not payment, not exchange, not reciprocal. Precesse names the mechanism: *how* it arrives — at 90° to the intended action — and that the geometry makes it predictable, not merely observed after the fact.

The distinction matters because it changes the operating posture:
- If non-transactional return is understood as outcome only, it is received as surprise — the gift that comes back unexpectedly, the consequence that wasn't aimed at.
- If precesse is understood as mechanism, it becomes anticipatable — the question is not "will something return?" but "what is the orthogonal geometry of this action, and what does that geometry guarantee?"

The posture shift: from receiving non-transactional return as grace to understanding precesse as structural law.

---

## Recognition Image

**The bee** — intends to gather nectar; pollination is the unavoidable orthogonal consequence of the geometry of its action. The mechanism is not magic. It is the angle.

---

## Edges

**The angle must exist.** Precesse requires orthogonal geometry — the action must have a consequence that is structurally 90° from the aim. Not all actions have this geometry. The pattern does not hold for actions whose consequences are all on the intended axis.

**Anticipation does not equal control.** Understanding that precesse will occur does not make the orthogonal consequence controllable. The bee cannot choose the pollination target. The mechanism is structural, not volitional.

**The wrong-action trap.** If the action is misaligned — aimed at the wrong thing — precesse still fires, but the orthogonal consequence is orthogonal to the wrong aim. Understanding precesse does not substitute for aim-quality; it amplifies whatever aim is present.

---

## Falsifier

If an action produces its intended consequence and the orthogonal return can be attributed to a different cause, precesse has not been demonstrated for that action — only non-transactional return has been observed. Precesse requires that the orthogonal consequence is structurally produced by the geometry of the action itself, not incidentally co-occurring with it.
