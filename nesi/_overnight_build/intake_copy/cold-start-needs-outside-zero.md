# Uncalibrated Regime Needs an Outside Zero

*slug: `cold-start-needs-outside-zero`*
*Promoted: 2026-07-21 · Source: The Membrane — human-gate pattern family*

---

## Transferable Form

Any instrument that judges "done" by feel needs a reference point — a zero — that only a completed crossing of that same type can deposit; description, instruction, and effort cannot install it. Before the first clean completion of a new kind of work, "stuck in a loop" and "genuinely not ready" feel identical, and the instrument reports both with equal confidence. The system can flag its own uncalibrated state, but no interior operation clears the flag — exit requires something outside: a reader who carries that zero, or one small crossing done purely to register it.

---

## Development

The mechanism is a calibration circuit with a missing reference voltage. Closure-discrimination works by comparing felt distance-to-closure against a registered somatic zero for that object-type. The zero is not a belief or a memory; it is a residue deposited only by a completed crossing of that type — the calibration event and the closure event are the same event. There is no side-channel installation.

The failure is silent, not noisy. The discriminator's output format is identical in calibrated and uncalibrated regimes: absent the zero, it does not error — it returns a confident reading computed against nothing. Loop-signature and genuine-not-ready are indistinguishable even to the approach-chart. Detection cannot be a live signal; the only flag mechanism is historical census — has this type ever had a clean crossing? — which makes the flag only as good as the type taxonomy.

Habitat boundary: types with objective, outside-the-body completion tests never enter this regime. The pattern lives exclusively in felt-closure types, and within that territory it is not an edge case but a standing property of expansion: the first crossing of any new object-type is by definition performed inside the uncalibrated regime. The growth-front of the system is permanently made of it.

Two remedies, each with a structural constraint. Second reader: only breaks the regime if the reader carries a registered zero for that type — a reader from the same practice-culture shares the calibration gap and merely doubles the confident indistinguishability. One deliberately forced clean crossing: works only if actually clean — a crossing contaminated by the forcing registers a corrupted zero, converting a never-registered zero into a wrongly-registered one (this pattern's failure mode becomes its sibling's, `translated_origin_failure_mode.md`). The safer form is a deliberately small, low-stakes calibration crossing whose only purpose is to register a zero.

The structural truth: the flag cannot lower itself. The system can announce "I am uncalibrated," yet no interior operation clears the state — exit is constitutively exterior, a bootstrapping requirement, not a best practice.

---

## Edges

The per-type calibration model itself is unevidenced — the load-bearing assumption, not a verified fact. The forced-crossing remedy may be self-defeating in exactly the regime it targets; carried flagged unsafe, not a co-equal exit alongside the second reader. The type-taxonomy regress is untouched: the census that raises the flag depends on a carving that is itself uncalibrated. The proposed low-stakes calibration-crossing move class is licensed but unnamed and untested.
