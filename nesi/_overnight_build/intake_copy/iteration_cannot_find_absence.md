## Statement

A refinement loop can only correct what its part list contains. Every feedback signal binds to an element that exists; a missing element has no coordinate on the error surface, so no amount of loop-speed produces a gradient toward it. The signature: a whole-system alarm that fires at the same pitch across repair cycles — detection without localization — while the version history, which records only presence-changes, cannot show the fault at all.

## Mechanism

Iteration is correction over a part list. Each signal attaches to a present element — this button, this phrasing — and repair moves the signal: defects in present elements attenuate across versions. An absent element has no attachment point; the loop's gradient is zero along the fault's axis regardless of velocity. Fast iteration on such a fault is fast motion on a plane that does not contain the fault's dimension.

**Detect and localize come apart.** A whole-system falsifier measuring felt effect at the boundary ("limits rather than opens") can detect a fault it has no vocabulary to name. Localization requires the generative vocabulary to already contain the missing element — exactly what an absence withholds. A falsifier that keeps firing without ever pointing is not broken; it is the signature of an absence.

**The runnable test — iteration-invariant firing.** Defects in present elements change pitch, move, or resolve as versions accumulate. An absence is iteration-invariant: the falsifier fires identically across versions because nothing in the loop touches its cause. Monotone firing across repair cycles is a pre-retrospective, in-flight test — it converts what looks like wasted iterations into diagnostic data. When your falsifier fires identically through n iterations, you are looking at one measurement, taken n times, of a fault class the loop cannot reach.

**The honest scope.** The blindness is a property of the generative frame's search space, not of iteration as such. A loop seeded with negation — an adversarial pass listing what a user might reach for and not find — generates absences from inside. The narrow claim: *unaugmented lineage-iteration misses absences.* That narrowness prescribes a fix (inject negation into the loop), not only a witness outside it.

## Live instance

Three chassis versions in six days (v1→v2→v3, 2026-06-27→07-02); the falsifier "limits rather than opens" fired identically across all three. Iteration added yes-forms; the missing verb (NO) had no diff line, no coordinate, and stayed missing at every speed. Located only by contact-surface use on 2026-07-04. (That missing NO-verb is the same absence that still gates [[surface_without_no]] — this pattern names why iteration could not find it.)

## Boundaries and failure modes

1. **Retrospective unfalsifiability.** After the fact, any defect can be relabeled an absence — hindsight always finds a hole. The pattern holds jurisdiction only where monotone firing was observable *before* the retrospective named the hole.
2. **Wrong-repair confound.** Monotone firing could also mean the repairs were incompetent, not that the fault is an absence. The test discriminates fault class only given competent repairs — and competence is not observable from the firing pattern alone. Carried face-up.
3. **Records.** Changelogs, diffs, and lineages are delta-representations — they render presence-changes only. Lineage records are provenance instruments, not fault detectors; a rich repair history can accumulate in which the failure never once appears.

## Conjecture line (not claimed as mechanism)

Contact-surface use may find absences because a reach-and-miss is a somatic event — but that sensor fires only along existing desire-paths, and the discovery event in the source instance was never narrated. Unfelt needs, missing rollback paths, and deep-stack faults are invisible to felt use exactly as they are to iteration. The system's sensing for that class is an open hole, not a solved one — this rhymes with [[proximity_instrument_horizon]] (the felt-read horizon).

## Falsifier

An absence-type fault located by unaugmented lineage-iteration (no negation seeding, no fresh contact) weakens the pattern; a falsifier that fires monotonically across competent repairs and turns out to be a present-element defect breaks the runnable test.
