## Transferable Form

When a conceptual layer is fully articulated and the execution layer is absent, the completeness of the concept is not evidence of readiness — it is a record of where the last attempt halted. The articulation discharged the internal drive that would otherwise have generated execution, closing the loop prematurely. The cleaner the specification, the more precisely it marks the ceiling of the previous run.

## Development

**Mechanism.** Articulating what an implementation would do performs the cognitive function of implementation without producing it. The felt urgency that drives building is satisfied by description; the loop closes before ignition. No execution is displaced or deferred-in-motion — execution never started. The conceptual layer is not a precursor to the execution layer; it is a substitute for it. The TODO is not a future instruction; it is a past disclosure of where someone stopped, written in the grammar of forward intent.

**Structural truth.** A complete conceptual layer above an empty execution layer is diagnostic-backward. Read forward, it looks like preparation. Read backward, it names the ceiling of the last attempt. The thoroughness of the concept is a liability signal, not an asset signal — it indicates the gap was fully known and not crossed.

**Failure mode.** The pattern is invisible under a readiness lens. A readiness lens reads the gap as preparation-not-yet-done. The diagnostic-backward read requires treating the concept layer's completeness as evidence of cessation rather than progress.

**Structural difference from displaced-loop.** A displaced loop is a running loop with a misaligned reference point — correctable by re-anchoring. This pattern shows no running loop. Cessation before ignition means there is nothing to re-anchor. Intervention requires a separate ignition event.

## Open edges

- What restarts a stopped loop? The pattern names cessation but cannot name ignition — the source material contains no example of the loop starting.
- The pattern holds a tension it cannot close: if articulation reliably substitutes for execution, the act of naming this pattern may itself be subject to it.
