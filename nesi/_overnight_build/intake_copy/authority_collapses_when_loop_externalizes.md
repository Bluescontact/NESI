## Transferable form

Some feedback loops are architecturally self-authorizing: the sensing organ and the deciding organ are the same undivided structure, and the loop's function depends on that unity remaining intact. When an external instrument is interposed and acquires decision authority, the loop does not gain redundancy — it is replaced by a two-node system where authority must be assigned to one node, and the analytical node wins by default because it is legible. The collapse is structural, not behavioral: the original loop atrophies not because the person trusts the device more but because the single-structure circuit has been topologically replaced.

## Mechanism

A self-governing loop where sensor and governor are the same structure produces its function through that undivided act. Interposing an external instrument creates two structures — one that reads, one that decides — and authority must now be negotiated between them. The analytical node is legible; the original node is not. Authority migrates not because the device is more accurate but because the two-node system cannot route authority to the unlegible node. The original loop, no longer exercised, atrophies.

**Domain boundary.** This pattern holds only in self-referential loops where the interior reading IS the function — where the loop was self-authorizing before instrumentation. A heart-rate monitor does not collapse cardiac function because the heart's authority was never routed through legibility. A device that replaces the question "how do I feel?" collapses somatic authority because that loop was self-authorizing. The distinguishing criterion is whether the loop's function required its own unmediated enactment.

**Collapse trigger.** The collapse is not caused by instrumentation per se but by authority routing. Passive logging never consulted at a decision moment runs alongside the original loop without replacing it. The mechanism collapses at the moment the device becomes the governor — when the body reads the device and acts on that reading instead of the raw signal.

**The transfer sequence** (four steps, each a precondition for the next):

1. **Architectural unity** — sensor and governor are one undivided structure. The loop's output is the person's own reading of the raw signal; no second data source is consulted.
2. **Interposition** — an external instrument begins reporting on the same domain the loop already governs. Two structures now exist where there was one.
3. **Authority assignment (the pivot)** — because the external report is more legible (numeric, portable, comparable across days) or the two structures disagree at least once, authority defaults to the legible structure — not because it's more accurate, but because a two-node system resolves ties toward whichever node a third party can check.
4. **Atrophy** — once the device is consulted at the decision moment instead of the raw signal, the original loop stops being exercised, and the skill of reading it degrades from disuse.

No interposition without unity first; no assignment without interposition; no atrophy without the assignment actually redirecting the decision moment.

## Failure modes

1. **Degraded baseline inverts the rule.** The pattern presupposes an intact self-governing instrument. Where somatic self-reading has been chronically overridden — by trauma, dissociation, or habituation — the direct channel is not more precise; it is systematically miscalibrated. External instrumentation in this case is not collapse but scaffold. The precondition the pattern requires is one it cannot verify from inside the loop.
2. **Latency breaks the acute/chronic boundary.** The pattern's "no latency" claim holds for acute governors (this meeting is wrong, stop now). For slow-accumulating states — cortisol load, chronic sleep deficit, progressive depletion — the somatic signal lags the measurable precursor by days or weeks. The pattern may hold precisely where it matters least and fail precisely where catastrophic drift accumulates.
3. **The pattern prohibits its own scaffold.** If external instrumentation always collapses the loop, then feedback-mediated skill development is impossible — yet direct somatic reading demonstrably improves through practice that often uses external reference points in early phases. A phase distinction (instrumentation appropriate in acquisition, collapses in deployment) resolves this, but is not present in the surviving material.

## Falsifier

If an external instrument is interposed on a genuinely self-authorizing loop and authority does NOT migrate to it — the person continues consulting the raw signal at the decision moment even when the device disagrees — the collapse mechanism is not operating for that dyad, regardless of how legible the device is. This would show the collapse is not automatic on interposition alone.

## Edges

What restores a collapsed loop after the device has held authority long enough that the original circuit has atrophied — and whether that restoration is possible or whether the topology shift is irreversible past a threshold — remains open. The precondition problem is also unresolved: the pattern requires an intact self-governing instrument but has no way to test for that from inside the loop.
