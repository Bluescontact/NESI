# THE ONE MODEL — what a written relation looks like

**The Tetra Builders Agreement is the only instance anywhere in this system with all six edges written.** Its section is called *"THE SIX EDGES (the relations that make it rigid)."* Every one is a single sentence about what holds between two vertices:

| | relation |
|---|---|
| WHAT–LAWS | *legal-but-out-of-scope is still out of scope; in-scope-but-unlawful never builds* |
| WHAT–PROOF | *scope defines what must be proven* |
| WHAT–AUTHORITY | *scope changes mid-pass are forks, not judgement calls* |
| LAWS–PROOF | *laws are verified behaviours, not assumptions* |
| LAWS–AUTHORITY | *no law is relaxed by any builder; only Kevin's mark amends a law* |
| PROOF–AUTHORITY | *the report is addressed to Kevin's gate* |

**Note the form.** None of them describes the two vertices. Each states **what is true because both exist** — a constraint that neither vertex carries alone. That is the shape of the twenty-one below, and none of them has it yet.
