# THE TETRA BUILDERS AGREEMENT
**Status:** SIGNED — Kevin's mark 2026-08-01 ("do it", riding the go that invokes this agreement for the ds-kit pass). Precedes every build pass's go from here. Previous status: DRAFT for Kevin's mark — once signed, this agreement precedes every build pass's go, standing. Nothing here is new law; it is the existing laws assembled into the minimal rigid cell, so an unattended builder carries the whole structure instead of a checklist.
**Shape:** four vertices, six edges — the tetra. Remove any vertex and the frame is a flapping hinge; that is why all four are stated on every pass.

## THE FOUR VERTICES

**V1 · WHAT (scope).** The pass builds exactly what its manifest names, inside the governing naming (`THE_WHOLE_NAMING_2026-07-31.md` as amended). Anything the documents do not decide is FLAGGED, never invented. Creates only inside its named directories; modifies nothing existing.

**V2 · LAWS (boundaries).** Carried whole into every pass, no restatement needed at go-time: the recognition law (the mechanic never does the recognizing) · no surveillance, no read receipts · the Deep never renders its contents · no scores, no completion affordances · nothing directs Kevin's body · the morning-pages guard (harvest the writing, never read the writer) · gift-only membrane, the receiver's mark makes the gift · light palette · no network calls in the built world · locate, never steer.

**V3 · PROOF (verification).** Definition of Done, binding: read sources in full before building · actually run/walk the build in a real browser before any done word · prove every round-trip · split the claims (mechanism-works is statable; does-what-Kevin-needed is only ever his) · name the edge of what was checked, including what automation could not reach.

**V4 · AUTHORITY (the gate).** Kevin's mark is the only go and the only acceptance. An unattended pass runs on decisions already marked; ambiguity resolves by document line (cited in the report) or becomes a flag. The report lists every self-resolved decision. Any flag is reversible by one mark. The builder never claims the felt-read.

## THE SIX EDGES (the relations that make it rigid)

1. **WHAT–LAWS:** legal-but-out-of-scope is still out of scope; in-scope-but-unlawful never builds.
2. **WHAT–PROOF:** scope defines what must be proven — every named deliverable appears in the verification evidence or in the not-proven list.
3. **WHAT–AUTHORITY:** scope changes mid-pass are forks, not judgment calls — they stop that item and flag it.
4. **LAWS–PROOF:** laws are verified behaviors, not assumptions (the Deep's refusal is walked into, not asserted).
5. **LAWS–AUTHORITY:** no law is relaxed by any builder for any reason; only Kevin's mark amends a law.
6. **PROOF–AUTHORITY:** the report is addressed to Kevin's gate — evidence first, flags plainly, the second claim left unmade.

## PER-PASS INVOCATION
Every pass's manifest ends with one line: *"This pass runs under the Tetra Builders Agreement, all four vertices."* That line makes the whole cell binding without re-deriving it.

**Falsifier:** if a pass would have been built identically without this agreement, it was ceremony. It earns its place the first time it stops an invention, forces a flag, or catches an unproven law.
