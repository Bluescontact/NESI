# RETIRED — 2026-08-27, Kevin's mark

> "we are composting the build experience, and remnants.. that project
> closed as incomplete/recycled"

**This tree is closed.** Unlike `nesi/world3d/`'s clean dead-end framing, this
one is named exactly as Kevin named it: **incomplete, and recycled** — not a
finished direction abandoned for a better one, but a build that stopped short
of done, whose real value is what can still be composted out of it, not what
it became. Nothing here is built against, extended, cited as current, or used
as a starting point. It is kept whole as a record — nothing deleted — the
same convention this corpus uses everywhere else: supersession is a mark on
top, never a silent erasure.

## What is live instead

`nesi/game2d/` — the 2D lattice. This tree's own Godot engine, its
`filters_panel.gd`/`writing_field.gd`/`heliostat_panel.gd`/`membrane_panel.gd`
station work, never crossed into it; a different engine, a different project,
never connected.

## The composting already underway — not proposed, already run

This is not a cold retirement. The gift-extraction pipeline (`library_lens.js`
→ `nesi/game2d/inbox/`) had already, before this mark, pulled five separate
capacities out of this exact tree and catalogued them as gift cards, each
citing its real source file and line range:

- **#2** — THE FILTERS, the drag-and-sort panel (`filters_panel.gd`) — routed,
  now live in `index.html`'s filter ground.
- **#4** — BLIND, the ephemeral writing mode (`writing_field.gd`) — routed,
  now live as the pad's blind toggle.
- **#5** — the arrived edit (`writing_main.gd:184-219`) — catalogued, not yet
  built; citation confirmed exact match.
- **#13** — the burn that never heals itself (`heliostat_panel.gd`) — a
  session-surviving, irreversible-consequence mechanic; catalogued.
- **#14** — a rule for the sheet, not a solver (`membrane_panel.gd`) — a
  cheap non-physics tension/tear mechanic; catalogued.

Two of five are already built into the live lattice. Three remain catalogued,
"ordered nothing, waiting for a mark" — exactly the pipeline's own discipline,
unaffected by this retirement. **Retiring the tree does not un-catalogue what
was already found in it**, and nothing above needs re-extraction.

## What was not composted, and is let go

Everything in this tree not named above or not already crossed into
`game2d` — the Godot scene tree itself, the store/tank data model, any
station or mechanic no gift card cites — closes with the tree. It is not
struck from the record; it is simply not carried forward. An incomplete
project does not owe a full accounting of everything it didn't finish.

## Status of prior work

No `RETIRED.md` existed for this tree before this mark. No document anywhere
in the repo had declared its status; every live instrument (`library_lens.js`'s
own root list, the six-root gift-mining pass, root `CLAUDE.md`'s "the live
build is `nesi/game2d/`") had already been treating it as retired by omission,
without anyone having said so. This file is that missing declaration, not a
new decision — it names what every other instrument already assumed.
