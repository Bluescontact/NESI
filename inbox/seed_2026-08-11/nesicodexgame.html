In NESI, GAME mechanics are the things a player actively does — a prompted action, a naming, a scan, a trust unlock — that produce a persistent, visible consequence in the world (a debuff cleared, a failing cell exposed, a tier unlocked, an address named). They are non-extractive play loops: the player supplies input from their own real state and terrain shifts in response, but nothing is taken from the player. Each mechanic is a repeatable verb with a way in, an act, and a legible aftermath.

Four Vertex Daily Practices

A daily one-line exercise per capacity vertex that clears the matching failure-mode debuff.

The pattern

A rotating micro-action tied to a specific capacity dimension: each day the player is prompted with one embodied, single-sentence practice targeting a named weakness. Completing the practice with real input (an actual position held, an actual limit named) discharges the debuff mapped to that vertex. The reusable pattern is a daily-quest slot where the reward is not loot but the removal of a status condition the player is currently carrying.

Four Failure Modes + Signal Catalog

A bestiary of four collapse patterns, each read from a visible signal and cured by supplying its missing vertex.

The pattern

Every failing NPC or system emits an observable signal that maps to one of four named failure modes (Dissolved, Isolated, Overflowing, Ephemeral), each the deficiency of a specific vertex. The player scans, names the mode, and the correct intervention is deterministically the missing vertex's practice. The reusable pattern is a diagnose-by-signal loop: observation becomes a named condition, and the name prescribes the fix.

Six-Lens Diagnostic Matrix

A 24-cell scan running any system through six frameworks across four movements to pinpoint the breakdown cell.

The pattern

A targeted system is passed through a 4x6 grid (four movements by six frameworks) and each cell is evaluated, so breakdown localizes to a specific coordinate rather than a vague sense of wrongness. The failing cell names both the framework lens and the movement where it fails, which specifies the intervention. The reusable pattern is a high-resolution inspect that converts a whole-system unease into one addressable coordinate.

Graduated Trust Framework (5-level)

A five-tier progression ladder where each capability tier unlocks only by demonstrated coherence at the prior one.

The pattern

Access expands through five gated tiers (Read-only, Bounded modification, Tool execution, Extended capabilities, Autonomous operation), and each gate opens only when coherence is demonstrated at the level below. Progression is earned by proof, not granted by time, so the ladder is a visible, persistent record of trust state. The reusable pattern is a demonstrated-coherence progression ladder that governs what actions a player/agent is even allowed to attempt.

Open Village Four-Movement Diagnostic

A four-step guided quest that ends each movement in a named, addressable finding rather than a score.

The pattern

A structured four-movement walkthrough asks which vertex dropped, which invisible layer is unheld (and who holds it), whether the four gift preconditions are met, and whether the architecture test passes — each movement resolving to an actionable finding with a name and an address. It is explicitly a tool to act with, not a quiz to grade. The reusable pattern is a guided diagnostic quest whose reward is a concrete target (a person, a layer, a precondition) you can then intervene on.

Synthesis — what this class does for NESI

Together these gifts form NESI's diagnose-name-repair-progress loop: the player scans a system (six-lens matrix, Open Village walkthrough), names its state (four failure modes), and repairs it by supplying the missing capacity (vertex daily practices), while the graduated trust ladder governs how much they're allowed to touch as their coherence grows. The four vertices are the shared coordinate system every mechanic points at, so a debuff, a failing cell, a failure mode, and a quest finding all resolve to the same four addresses. What the player actually does is convert vague felt wrongness — in themselves, an NPC, or a system — into a named, embodied, addressable target, then take one real single-sentence action that clears it and leaves a visible mark on the terrain. Nothing is extracted: the input is the player's own real position, limit, or observation, and the persistent consequence is a debuff cleared, a cell healed, or a tier unlocked.
